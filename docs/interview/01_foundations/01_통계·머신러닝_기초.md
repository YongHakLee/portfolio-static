# 기초개념 1 — 통계 · 머신러닝

---

## 이 문서를 읽는 법

이 문서는 나머지 모든 문서의 바닥이다. 딥러닝 논문을 읽을 때도 "왜 이 손실함수인가", "이 평가지표가 왜 적절한가", "과적합을 어떻게 알았나" 같은 질문은 결국 여기로 돌아온다.

응용통계학 전공자에게 면접관이 기대하는 것은 두 가지다. 하나는 **통계적 사고**로, 데이터를 보고 무엇이 편향을 만드는지 짚어내는 능력이다. 다른 하나는 **모델 선택의 근거**로, 왜 딥러닝이 아니라 트리 모델을 썼는지 같은 판단을 설명하는 능력이다. 전공이 통계라는 사실 자체가 "이 사람은 여기는 확실히 알겠지"라는 기대를 만들기 때문에, 이 문서의 개념은 다른 어떤 문서보다 확실하게 답할 수 있어야 한다.

각 개념은 **직관 → 정의 → 핵심 수식 → 면접 포인트** 순서다. 수식은 결과식만 적고 기호를 하나씩 풀이했다. 유도 과정은 넣지 않았다. 면접에서 유도를 시키는 경우는 드물고, 시키더라도 기호의 의미를 정확히 아는 쪽이 먼저다.

읽는 순서는 위에서 아래로가 자연스럽지만, 급하다면 **정규화 · 편향-분산 · 랜덤 포레스트 · 그래디언트 부스팅 · 분류 평가지표 · 회귀 평가지표 · 클래스 불균형** 일곱 개를 먼저 본다. 실제 면접에서 이 일곱 개가 가장 자주 나온다.

## 개념 목록

### 지도학습과 비지도학습

**직관**

지도학습은 답이 적힌 문제집으로 공부하는 것이다. 문제(입력)와 정답(레이블)이 짝지어져 있고, 모델은 문제를 보고 정답을 맞히는 규칙을 배운다. 비지도학습은 정답이 없는 자료 더미를 주고 "여기서 뭔가 패턴을 찾아봐"라고 시키는 것이다. 비슷한 것끼리 묶거나(군집화), 데이터를 더 적은 축으로 요약하는(차원축소) 일이 여기에 속한다.

중간 지대도 있다. **준지도학습**은 레이블이 붙은 데이터가 조금, 안 붙은 데이터가 잔뜩 있을 때 쓴다. 레이블링에 사람 손이 많이 드는 의료 영상이나 분할(segmentation) 과제에서 특히 중요하다.

**정의**

- 지도학습(Supervised Learning): 입력 x와 레이블 y의 쌍으로 학습해, 새로운 x에 대한 y를 예측하는 함수 f를 찾는다. 목표 변수가 연속이면 회귀, 범주면 분류다.
- 비지도학습(Unsupervised Learning): 레이블 없이 데이터의 구조를 찾는다. 군집화, 차원축소, 밀도추정, 이상탐지가 대표적이다.
- 준지도학습(Semi-Supervised Learning): 소량의 레이블 데이터와 대량의 비레이블 데이터를 함께 쓴다.
- 강화학습(Reinforcement Learning): 정답 대신 보상 신호를 받으며 시행착오로 정책을 학습한다. 자세한 것은 [06_강화학습·시계열·기타.md](06_강화학습·시계열·기타.md)를 본다.

**면접 포인트**

"준지도학습이 왜 필요한가"라는 질문이 T07 논문(준지도 시맨틱 분할)과 연결된다. 답의 핵심은 **레이블링 비용**이다. 분할 과제는 픽셀 단위로 사람이 칠해야 해서 이미지 한 장에 수십 분이 든다. 이때 레이블 없는 데이터를 활용할 수 있으면 성능 대비 비용이 크게 떨어진다.

### 선형회귀

**직관**

점들이 흩어져 있을 때 그 사이를 가장 잘 지나가는 직선을 긋는 것이다. "가장 잘"의 기준은 각 점에서 직선까지의 세로 거리를 제곱해 모두 더한 값이 최소가 되는 것이다. 제곱을 쓰는 이유는 두 가지다. 부호를 없애야 위아래 오차가 상쇄되지 않고, 큰 오차에 더 큰 벌점을 주기 위해서다.

**정의**

입력 변수들의 가중합으로 연속형 목표 변수를 예측하는 모형이다. 최소제곱법(OLS)으로 계수를 추정한다.

**핵심 수식**

예측식:

```
ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₚxₚ
```

- `ŷ`: 예측값
- `β₀`: 절편. 모든 입력이 0일 때의 예측값
- `βⱼ`: j번째 변수의 회귀계수. **다른 변수를 고정했을 때** xⱼ가 1 늘면 예측값이 얼마나 변하는지
- `p`: 입력 변수 개수

손실함수(잔차제곱합):

```
RSS = Σᵢ (yᵢ - ŷᵢ)²
```

- `yᵢ`: i번째 관측의 실제값
- `ŷᵢ`: i번째 관측의 예측값

**면접 포인트**

회귀계수 해석에서 "다른 변수를 고정했을 때"라는 조건을 빼먹으면 감점이다. 이 조건이 있기 때문에 변수 간 상관이 높으면(다중공선성) 계수가 불안정해진다. 3D 계측 논문들(T03·T04·T05)에서 길이로부터 무게·둘레를 추정하는 회귀식이 나오는데, 이때 입력이 되는 여러 길이 값들은 서로 상관이 높다. 이 문제를 어떻게 다뤘는지는 각 논문 문서에서 확인한다.

### 로지스틱 회귀

**직관**

선형회귀의 출력은 아무 실수나 될 수 있는데, 확률은 0과 1 사이여야 한다. 그래서 선형식의 결과를 S자 곡선(시그모이드)에 통과시켜 0~1로 눌러 담는다. 이름은 회귀지만 하는 일은 분류다.

**정의**

이진 분류에서 사건이 일어날 확률을 로그 오즈(log-odds)의 선형 결합으로 모형화한다.

**핵심 수식**

```
P(y=1|x) = 1 / (1 + e^(-z)),   z = β₀ + β₁x₁ + ... + βₚxₚ
```

- `z`: 선형 결합값. 로짓(logit)이라 부른다
- `e`: 자연상수

손실함수(이진 교차엔트로피):

```
L = -(1/n) Σᵢ [ yᵢ log(p̂ᵢ) + (1-yᵢ) log(1-p̂ᵢ) ]
```

- `p̂ᵢ`: 모델이 예측한 확률
- `yᵢ`: 실제 레이블 (0 또는 1)

실제 레이블이 1이면 앞항만, 0이면 뒷항만 살아남는다. 정답 쪽 확률이 1에 가까울수록 손실이 0에 가까워진다.

**면접 포인트**

교차엔트로피는 딥러닝 분류에서도 그대로 쓰인다. "왜 분류에 MSE를 안 쓰나"라는 질문이 나오면, 시그모이드와 MSE를 함께 쓰면 기울기가 매우 작아지는 구간이 생겨 학습이 느려진다는 점, 그리고 교차엔트로피가 최대우도추정과 일치한다는 점을 말한다.

### 손실함수와 최적화

**직관**

손실함수는 "지금 모델이 얼마나 틀렸는지"를 하나의 숫자로 요약한 것이다. 최적화는 그 숫자를 줄이는 방향으로 모델의 파라미터를 조금씩 옮기는 과정이다. 안개 낀 산에서 내려오는 것에 비유한다. 발밑의 기울기만 보고 가장 가파른 내리막 방향으로 한 걸음씩 내딛는다.

**정의**

- 손실함수(Loss Function): 예측과 정답의 불일치를 측정하는 함수. 회귀는 MSE·MAE·Huber, 분류는 교차엔트로피를 주로 쓴다.
- 경사하강법(Gradient Descent): 손실함수의 기울기(gradient) 반대 방향으로 파라미터를 갱신한다.

**핵심 수식**

```
θ ← θ - η ∇θ L
```

- `θ`: 모델 파라미터
- `η`: 학습률(learning rate). 한 걸음의 크기
- `∇θ L`: 손실함수를 파라미터로 미분한 기울기 벡터

**면접 포인트**

MSE와 MAE의 차이를 묻는 질문이 잦다. MSE는 오차를 제곱하므로 큰 오차(이상치)에 훨씬 민감하고, MAE는 모든 오차를 같은 비중으로 다뤄 이상치에 강건하다. 3D 계측처럼 대부분 잘 맞다가 가끔 크게 틀리는 상황(예: 키포인트 하나가 엉뚱한 곳에 잡힘)에서는 MAE나 Huber 손실이 더 안정적이다.

### 과적합과 편향-분산 트레이드오프

**직관**

학생이 기출문제 답을 통째로 외우면 그 문제집에서는 만점이지만 새 문제는 못 푼다. 이게 과적합이다. 반대로 공부를 너무 대충 하면 기출도 새 문제도 다 못 푼다. 이게 과소적합이다.

**편향(bias)** 은 모델이 너무 단순해서 진짜 패턴을 못 잡는 정도, **분산(variance)** 은 학습 데이터가 조금만 바뀌어도 모델이 크게 달라지는 정도다. 모델을 복잡하게 만들면 편향은 줄고 분산은 는다. 둘의 합이 최소가 되는 지점이 최적이다.

**정의**

예측 오차는 편향의 제곱, 분산, 줄일 수 없는 잡음의 합으로 분해된다.

**핵심 수식**

```
E[(y - f̂(x))²] = Bias[f̂(x)]² + Var[f̂(x)] + σ²
```

- `Bias[f̂(x)]`: 모델 예측의 기댓값과 참값의 차이
- `Var[f̂(x)]`: 학습 데이터를 바꿔 가며 학습했을 때 예측이 흔들리는 정도
- `σ²`: 데이터 자체의 잡음. 어떤 모델로도 줄일 수 없다

**면접 포인트**

과적합을 **어떻게 알아차렸는지**를 묻는 후속 질문이 반드시 따라온다. 답은 "학습 손실은 계속 떨어지는데 검증 손실이 어느 시점부터 올라간다"이고, 대응은 정규화·조기종료·데이터 증강·모델 축소·더 많은 데이터 순서로 말한다.

※ 배경 보충 — 최근 대형 신경망에서는 파라미터를 계속 늘리면 검증 오차가 다시 떨어지는 이중 하강(double descent) 현상이 보고돼 있다. 고전적 편향-분산 곡선이 항상 성립하지는 않는다는 뜻인데, 면접에서 먼저 꺼낼 필요는 없고 상대가 언급하면 알고 있다고 답하는 정도면 된다.

### 정규화 (L1 / L2)

**직관**

모델이 학습 데이터에 과하게 맞춰지는 걸 막으려면, 계수가 너무 커지지 않게 벌점을 준다. L2는 계수를 전체적으로 작게 눌러 0 근처로 모으고, L1은 일부 계수를 아예 정확히 0으로 만들어 변수를 골라낸다.

왜 L1은 0을 만들고 L2는 못 만드는가. 제약 영역의 모양 때문이다. L1의 제약 영역은 마름모라 꼭짓점(축 위, 곧 계수가 0인 지점)에서 손실 등고선과 만나기 쉽다. L2는 원이라 꼭짓점이 없어 축에 정확히 닿기 어렵다.

**정의**

- L1 정규화(Lasso): 계수 절댓값의 합에 벌점. 변수 선택 효과가 있다.
- L2 정규화(Ridge): 계수 제곱합에 벌점. 상관 높은 변수들의 계수를 고르게 나눠 갖는다.
- Elastic Net: 둘을 섞는다.

**핵심 수식**

```
L1:  L = RSS + λ Σⱼ |βⱼ|
L2:  L = RSS + λ Σⱼ βⱼ²
```

- `λ`: 정규화 강도. 크면 계수를 더 세게 누른다. 0이면 일반 회귀와 같다
- `βⱼ`: j번째 회귀계수

**면접 포인트**

딥러닝의 **가중치 감쇠(weight decay)** 가 사실상 L2 정규화라는 점을 알아 두면 좋다. 또 정규화 전에 **변수 표준화**가 필요하다는 점도 자주 묻는다. 단위가 다른 변수들에 같은 벌점을 매기면 단위가 큰 변수만 억울하게 눌리기 때문이다.

### 교차검증

**직관**

데이터를 한 번만 학습/검증으로 나누면, 그 나눔이 우연히 유리하거나 불리할 수 있다. 데이터를 K조각으로 나눠 돌아가며 한 조각씩 검증에 쓰고 나머지로 학습하면, K개의 성능을 얻어 평균을 낼 수 있다. 운의 영향을 줄이는 방법이다.

**정의**

- K-Fold: 데이터를 K등분해 K번 학습·검증하고 평균낸다. 보통 K=5 또는 10.
- Stratified K-Fold: 각 폴드의 클래스 비율을 원본과 같게 유지한다. 불균형 데이터에서 필수다.
- Leave-One-Out: K를 데이터 개수만큼. 데이터가 아주 적을 때.
- 시계열 교차검증: 과거로 학습해 미래를 검증한다. 시간 순서를 섞으면 미래 정보가 새어 들어간다.

**면접 포인트**

**데이터 누수(data leakage)** 와 엮어 묻는 경우가 많다. 표준화나 결측 대치 같은 전처리를 전체 데이터에 먼저 적용하고 나서 폴드를 나누면, 검증 폴드의 정보가 학습에 새어 든다. 전처리는 반드시 폴드 안에서 학습 데이터로만 적합시켜야 한다.

P2(가스배관) 같은 센서 시계열 과제에서는 **같은 주행 세션의 데이터가 학습과 검증에 나뉘어 들어가는 것**도 누수다. 세션 단위로 나눠야 한다.

### 결정트리

**직관**

스무고개다. "이 값이 5보다 큰가?"로 데이터를 둘로 가르고, 각 조각에서 다시 질문을 던진다. 질문을 고르는 기준은 "이 질문으로 나눴을 때 각 조각이 얼마나 순수해지는가"다.

**정의**

입력 공간을 축에 평행한 경계로 반복 분할해, 각 영역에서 다수 클래스(분류) 또는 평균값(회귀)을 예측하는 모델이다.

**핵심 수식**

지니 불순도:

```
Gini = 1 - Σₖ pₖ²
```

- `pₖ`: 해당 노드에서 클래스 k의 비율

모든 샘플이 한 클래스면 Gini=0(완전 순수), 클래스가 고르게 섞이면 최대가 된다. 엔트로피 `-Σₖ pₖ log pₖ`를 쓰기도 하며 결과는 대체로 비슷하다.

**면접 포인트**

트리의 장점은 **비선형 관계와 변수 간 상호작용을 자동으로 잡고, 변수 스케일에 영향받지 않으며, 결과를 사람이 읽을 수 있다**는 것이다. 단점은 단일 트리는 분산이 커서 데이터가 조금만 바뀌어도 구조가 확 달라진다는 것이다. 이 단점을 앙상블로 해결한 것이 랜덤 포레스트와 부스팅이다.

---

### 랜덤 포레스트

**직관**

한 사람의 판단은 편향될 수 있으니 여러 사람에게 물어 다수결을 한다. 단, 모두가 같은 자료를 보면 같은 편향을 갖게 되므로, 각자에게 조금씩 다른 자료(부트스트랩 표본)와 다른 관점(변수 일부만)을 준다. 이렇게 만든 트리들의 예측을 평균낸다.

**정의**

배깅(bootstrap aggregating)에 **변수 무작위 선택**을 추가한 앙상블이다. 각 트리는 부트스트랩 표본으로 학습하고, 각 분할에서 전체 변수 중 일부만 후보로 고려한다.

**핵심 수식**

서로 상관이 ρ인 B개 예측을 평균할 때의 분산:

```
Var = ρσ² + (1-ρ)σ²/B
```

- `σ²`: 개별 트리 예측의 분산
- `ρ`: 트리 예측들 사이의 상관
- `B`: 트리 개수

B를 늘리면 뒷항은 0으로 가지만 앞항 `ρσ²`는 남는다. 그래서 **트리를 더 만드는 것보다 트리끼리 덜 닮게 만드는 것(ρ를 낮추는 것)이 중요하다.** 변수 무작위 선택이 하는 일이 정확히 이것이다.

**면접 포인트**

이 수식은 "랜덤 포레스트에서 변수를 무작위로 고르는 이유"라는 질문의 정확한 답이다. 배깅만으로는 트리들이 강한 변수 하나에 다 같이 의존해 서로 닮아 버린다.

P2(가스배관)에서 다층 신경망 대신 트리 기반 모델을 택한 판단의 근거로도 쓸 수 있다. 입력 길이 제약이 없고, 파생변수와 궁합이 좋으며, 데이터가 많지 않을 때 안정적이다.

### 그래디언트 부스팅과 LightGBM

**직관**

랜덤 포레스트가 여러 사람에게 동시에 물어 평균내는 것이라면, 부스팅은 한 사람이 푼 뒤 **틀린 부분만 다음 사람이 집중해서 고치는** 방식이다. 순차적으로 오차를 줄여 나간다.

**정의**

이전 모델의 잔차(정확히는 손실함수의 음의 기울기)를 다음 약한 학습기가 예측하도록 순차적으로 쌓는 앙상블이다.

**핵심 수식**

```
Fₘ(x) = Fₘ₋₁(x) + ν · hₘ(x)
```

- `Fₘ`: m번째 단계까지의 누적 모델
- `hₘ`: m번째로 추가되는 약한 학습기(보통 얕은 트리). 직전 모델의 음의 기울기를 근사한다
- `ν`: 학습률(shrinkage). 보통 0.01~0.1. 작을수록 트리를 많이 필요로 하지만 일반화가 좋다

**LightGBM의 차별점**

| 항목 | 일반 GBM | LightGBM |
|------|----------|----------|
| 트리 성장 | 레벨 단위(level-wise) | 잎 단위(leaf-wise) — 손실이 가장 크게 줄어드는 잎을 우선 분할 |
| 분할점 탐색 | 모든 값 정렬 후 탐색 | 히스토그램 기반으로 구간화해 탐색 |
| 대용량 처리 | 느림 | GOSS·EFB로 샘플·변수를 줄여 가속 |

잎 단위 성장은 빠르고 정확하지만 트리가 깊어져 과적합하기 쉬워서, `num_leaves`와 `min_data_in_leaf`로 제어해야 한다.

**면접 포인트**

"랜덤 포레스트와 부스팅 중 언제 무엇을 쓰나"가 단골이다. 랜덤 포레스트는 **분산을 줄이는** 방법이라 튜닝이 덜 민감하고 병렬화가 쉽다. 부스팅은 **편향을 줄이는** 방법이라 성능 상한이 높지만 학습률·트리 수·깊이를 함께 조율해야 하고 과적합에 더 취약하다. 정형 데이터에서 최고 성능이 필요하면 부스팅, 빠르고 안정적인 기준선이 필요하면 랜덤 포레스트로 답한다.

### 특징 공학과 파생변수

**직관**

모델에게 원자료를 그대로 던지면 스스로 패턴을 찾아야 한다. 대신 "이 구간의 변동성", "직전 값과의 차이"처럼 사람이 아는 힌트를 미리 계산해 주면 훨씬 쉽게 배운다. 딥러닝이 특징 추출을 자동화했다고 하지만, 정형 데이터와 센서 신호에서는 여전히 사람이 만든 파생변수가 강력하다.

**정의**

원본 변수로부터 문제에 유용한 새 변수를 만드는 작업이다. 센서 시계열에서 자주 쓰는 것:

| 파생변수 | 계산 | 무엇을 잡아내나 |
|----------|------|-----------------|
| 이동평균 | 윈도 내 평균 | 추세, 잡음 제거 |
| 이동분산·표준편차 | 윈도 내 분산 | 변동성, 급격한 변화 구간 |
| 최대-최소 차이(range) | max − min | 진폭, 스파이크 |
| 1차 차분 | xₜ − xₜ₋₁ | 변화율, 방향 전환 |
| 왜도·첨도 | 3·4차 적률 | 분포 비대칭, 꼬리 두께 |
| 자기상관 | 시차 상관계수 | 주기성 |

**면접 포인트**

P2(가스배관)에서 원본 신호 대신 분산·최대-최소 차이·행 간 변화량을 만들어 쓴 것이 이 개념의 직접 사례다. 왜 그렇게 했는지 설명할 때, "신경망이 안 돼서 트리로 바꿨다"보다 **"입력 길이가 가변인 신호를 고정 길이 특징 벡터로 요약해야 했고, 접합부·만곡부는 절대값보다 국소 변동에서 드러난다고 판단했다"** 는 쪽이 훨씬 좋은 답이다.

### 차원축소 (PCA)

**직관**

3차원 물체에 손전등을 비춰 벽에 그림자를 만든다고 하자. 어느 각도로 비추느냐에 따라 그림자가 물체를 잘 보여주기도, 뭉개기도 한다. PCA는 **정보(분산)를 가장 많이 남기는 각도**를 찾아 그림자를 만드는 방법이다.

**정의**

데이터의 분산이 최대가 되는 직교 방향(주성분)을 순서대로 찾아, 상위 몇 개 축으로 데이터를 사영하는 선형 차원축소 기법이다. 공분산 행렬의 고유벡터가 주성분이고, 고유값이 그 방향의 분산이다.

**핵심 수식**

k번째 주성분이 설명하는 분산 비율:

```
설명분산비율 = λₖ / Σⱼ λⱼ
```

- `λₖ`: k번째 고유값

**면접 포인트**

PCA는 **비지도**이며 목표 변수를 전혀 보지 않는다. 그래서 분산이 큰 방향이 예측에 유용한 방향과 다를 수 있다. 이 한계를 메운 것이 바로 다음의 PLS다. 두 개념은 세트로 물어보는 경우가 많다.

PCA 전에 표준화가 필요한 이유도 자주 묻는다. 분산 기준이므로 단위가 큰 변수가 주성분을 독차지하기 때문이다.

---

### PLS와 PLS-DA

**직관**

PCA가 "입력 데이터 안에서 가장 잘 퍼진 방향"을 찾는다면, PLS는 **"입력과 출력이 함께 잘 움직이는 방향"** 을 찾는다. 목표 변수를 보면서 축을 고른다는 점이 결정적 차이다.

PLS-DA는 PLS를 분류에 쓰는 것이다. 클래스 레이블을 더미 변수로 바꿔 출력에 넣고 PLS를 돌린 뒤, 예측값으로 클래스를 판정한다.

**정의**

- PLS(Partial Least Squares): 입력 X와 출력 Y의 공분산이 최대가 되는 잠재변수를 순차적으로 추출해 회귀하는 방법. 변수가 관측치보다 많거나 다중공선성이 심할 때 강하다.
- PLS-DA(Discriminant Analysis): PLS를 분류 문제에 적용한 것.

**핵심 수식**

첫 번째 잠재변수의 가중치 벡터 w는 다음을 최대화한다:

```
max  Cov(Xw, y)   subject to  ‖w‖ = 1
```

- `Xw`: 입력을 w 방향으로 사영한 잠재변수(스코어)
- `Cov`: 공분산. PCA라면 여기가 `Var(Xw)`가 된다

**면접 포인트**

P4(영상 기반 미세먼지 추정)와 T09 논문에서 PLS-DA를 쓴 근거로 이어진다. 영상 프레임에서 뽑은 특징들은 서로 상관이 매우 높고(인접 프레임·인접 픽셀), 표본 수 대비 변수 수가 많다. 이런 상황이 정확히 PLS가 강한 조건이다. "왜 그냥 회귀나 랜덤 포레스트가 아니라 PLS인가"라는 질문에 이 근거를 대면 된다.

화학계량학(chemometrics)과 대사체학에서 표준 도구로 쓰인다는 점도 알아 두면 좋다. 분광 데이터가 정확히 같은 성질(고차원·고상관)을 갖기 때문이다.

### 분류 평가지표 (정확도·정밀도·재현율·F1·AUC)

**직관**

암 진단 모델이 "전부 정상"이라고만 답해도, 실제 환자가 1%뿐이면 정확도는 99%다. 정확도 하나로는 아무것도 알 수 없다는 뜻이다. 그래서 **무엇을 놓치면 안 되는가**에 따라 지표를 골라야 한다.

**정의**

혼동 행렬:

|  | 예측 양성 | 예측 음성 |
|---|---|---|
| **실제 양성** | TP | FN |
| **실제 음성** | FP | TN |

**핵심 수식**

```
정확도(Accuracy)  = (TP + TN) / (TP + TN + FP + FN)
정밀도(Precision) = TP / (TP + FP)
재현율(Recall)    = TP / (TP + FN)
F1                = 2 · (정밀도 × 재현율) / (정밀도 + 재현율)
```

- 정밀도: **양성이라고 한 것 중** 진짜 양성의 비율. 오경보를 줄이고 싶을 때
- 재현율: **진짜 양성 중** 잡아낸 비율. 놓치면 안 될 때
- F1: 둘의 조화평균. 한쪽만 높은 경우를 걸러낸다

ROC-AUC는 임계값을 0에서 1까지 바꿔 가며 (거짓양성률, 재현율) 점을 찍어 만든 곡선 아래 면적이다. 임계값에 무관한 순위 매김 능력을 본다. 무작위 모델이 0.5, 완벽한 모델이 1.0이다.

**면접 포인트**

두 가지를 준비한다.

첫째, **정밀도와 재현율의 트레이드오프**. 임계값을 낮추면 재현율이 오르고 정밀도가 떨어진다. 어느 쪽을 택할지는 오류의 비용이 결정한다. 가스배관 접합부 탐지라면 놓치는 쪽(FN)이 위험하므로 재현율 우선이다.

둘째, **불균형 데이터에서 ROC-AUC보다 PR-AUC**. 음성이 압도적으로 많으면 FP가 늘어도 거짓양성률은 거의 안 변해서 ROC-AUC가 낙관적으로 보인다. 이때는 정밀도-재현율 곡선의 면적을 보는 것이 정직하다.

### 회귀 평가지표 (MAE·RMSE·MAPE·R²)

**직관**

"평균 2cm 틀렸다"와 "평균 3% 틀렸다"는 다른 정보다. 계측 과제에서는 절대 오차와 상대 오차를 모두 봐야 한다. 손목 둘레 2cm 오차와 허리 둘레 2cm 오차는 실용적 의미가 전혀 다르기 때문이다.

**핵심 수식**

```
MAE  = (1/n) Σ |yᵢ - ŷᵢ|
RMSE = √( (1/n) Σ (yᵢ - ŷᵢ)² )
MAPE = (100/n) Σ |yᵢ - ŷᵢ| / |yᵢ|     (%)
R²   = 1 - Σ(yᵢ - ŷᵢ)² / Σ(yᵢ - ȳ)²
```

- `ȳ`: 실제값의 평균
- R²는 "평균으로만 예측하는 것보다 얼마나 나은가"다. 1이면 완벽, 0이면 평균 예측과 같음, 음수면 평균보다 못함

| 지표 | 단위 | 이상치 민감도 | 특징 |
|------|------|---------------|------|
| MAE | 원 단위(cm 등) | 낮음 | 해석이 직관적 |
| RMSE | 원 단위 | 높음 | 큰 오차에 벌점. 항상 MAE 이상 |
| MAPE | % | 중간 | 크기가 다른 대상 비교에 유용. 실제값이 0 근처면 폭발 |
| R² | 무단위 | 중간 | 분산 설명력. 대상의 분산이 작으면 낮게 나옴 |

**면접 포인트**

3D 계측 논문 3편(T03·T04·T05)이 모두 이 지표들로 평가된다. 각 논문의 수치를 외울 때 **어떤 지표인지 함께 외운다.** "MAE 몇 cm"인지 "MAPE 몇 %"인지 헷갈리면 신뢰를 잃는다.

R²가 낮게 나오는 상황도 준비해 둔다. 측정 대상 집단의 실제 편차가 작으면(예: 비슷한 체형만 모은 데이터) 분모가 작아져 R²가 낮게 나오는데, 이는 모델이 나쁜 게 아니라 데이터 구성의 문제일 수 있다.

### 클래스 불균형 다루기

**직관**

100장 중 3장에만 결함이 있는 데이터로 학습하면, 모델은 "전부 정상"이라고 답하는 게 손실을 줄이는 지름길이라고 배운다. 소수 클래스를 제대로 배우게 하려면 데이터·손실·평가 세 군데에서 손을 봐야 한다.

**정의와 대응 방법**

| 층위 | 방법 | 주의점 |
|------|------|--------|
| 데이터 | 소수 클래스 오버샘플링, SMOTE로 합성 | 검증 폴드에는 적용하지 않는다. 과적합 위험 |
| 데이터 | 다수 클래스 언더샘플링 | 정보 손실 |
| 손실 | 클래스 가중치 부여 | 가중치 과다 시 FP 급증 |
| 손실 | Focal Loss — 쉬운 샘플의 기여를 낮춤 | 검출 과제에서 표준적으로 쓰임 |
| 임계값 | 결정 임계값 조정 | 모델 재학습 없이 가능. 먼저 시도할 것 |
| 평가 | PR-AUC, F1, 클래스별 재현율 | 정확도만 보면 안 됨 |

**핵심 수식**

Focal Loss:

```
FL(pₜ) = -αₜ (1 - pₜ)^γ log(pₜ)
```

- `pₜ`: 정답 클래스에 대한 예측 확률
- `γ`: 집중 파라미터. 보통 2. 이미 잘 맞히는 샘플(pₜ가 1에 가까움)의 손실 기여를 크게 줄인다
- `αₜ`: 클래스별 가중치

**면접 포인트**

"먼저 무엇을 시도하겠나"라는 질문에는 **임계값 조정**을 먼저 말하는 게 좋다. 비용이 0이고 재학습이 필요 없기 때문이다. 그 다음이 클래스 가중치, 마지막이 샘플링이다. SMOTE를 먼저 꺼내면 "그전에 할 게 있지 않나"라는 반문이 들어온다.

### 통계적 가설검정과 p-value

**직관**

동전을 10번 던져 앞면이 9번 나왔다. 이 동전이 공정하다면 이런 일이 얼마나 드물까? 드물수록 "공정하다"는 가정을 의심하게 된다. p-value는 **귀무가설이 참이라고 가정했을 때, 관측된 것만큼 극단적인 결과가 나올 확률**이다.

**정의**

- 귀무가설(H₀): 효과가 없다는 가정
- 대립가설(H₁): 효과가 있다는 주장
- 유의수준 α: 귀무가설이 참인데 기각해 버리는 오류(1종 오류)를 허용할 상한. 보통 0.05
- p-value < α이면 귀무가설을 기각한다

| 오류 | 뜻 | 비유 |
|------|-----|------|
| 1종 오류(α) | 참인 H₀를 기각 | 무죄인 사람을 유죄 판결 |
| 2종 오류(β) | 거짓인 H₀를 채택 | 유죄인 사람을 무죄 방면 |
| 검정력(1−β) | 진짜 효과를 찾아낼 확률 | 표본이 클수록 높아진다 |

**면접 포인트**

p-value에 대한 흔한 오해 두 가지를 정확히 구분할 수 있어야 한다. 통계 전공자에게는 이걸 틀리면 치명적이다.

- p-value는 **"귀무가설이 참일 확률"이 아니다.** 귀무가설이 참이라는 조건 하에서 데이터가 나올 확률이다. 조건이 반대다.
- p-value가 작다고 **효과가 크다는 뜻이 아니다.** 표본이 아주 크면 실용적으로 무의미한 차이도 유의하게 나온다. 그래서 효과크기(effect size)와 신뢰구간을 함께 봐야 한다.

모델 비교에서도 쓰인다. 두 모델의 성능 차이가 우연인지 보려면 교차검증 폴드별 성능에 대응표본 t검정을 하거나, 부트스트랩 신뢰구간을 만든다.

## 예상 질문

#### Q001. 통계학 전공이신데, 통계와 머신러닝의 차이를 어떻게 보시나요? 🟢

**의도:** 전공자로서 자기 정체성을 어떻게 정리했는지, 그리고 두 분야를 피상적으로 아는지 본다. 통계 전공자에게는 거의 반드시 나오는 질문이다.

**답변:** 목적의 차이라고 봅니다. 통계는 데이터를 만들어 낸 구조를 설명하고 그 추정의 불확실성을 정량화하는 데 무게가 있습니다. 계수가 유의한지, 신뢰구간이 어느 정도인지를 묻습니다. 머신러닝은 새로운 데이터에 대한 예측 성능이 우선이라, 모델이 해석되지 않아도 잘 맞으면 받아들입니다. 다만 실무에서는 둘을 나눠 쓰지 않았습니다. 예측 성능이 필요한 지점에는 머신러닝 모델을 쓰되, 왜 그 성능이 나오는지 확인할 때는 통계적 사고가 필요했습니다. 가스배관 과제에서 모델을 바꾸기 전에 어떤 변수가 신호를 담고 있는지부터 확인한 것이 그런 경우입니다.

**꼬리질문:** 그럼 해석이 필요 없는 상황이라면 통계적 접근은 필요 없는 건가요?

#### Q002. 과적합이 일어났다는 걸 어떻게 알아차리시나요? 🟢

**의도:** 실제로 모델을 학습시켜 본 사람인지 확인한다. 교과서적 정의만 말하면 경험이 없다고 판단한다.

**답변:** 학습 손실은 계속 떨어지는데 검증 손실이 어느 시점부터 다시 올라가면 과적합으로 봅니다. 학습 곡선을 매번 그려서 그 분기점을 확인했습니다. 다만 검증 손실이 안 오르는데도 과적합인 경우가 있어서, 학습 성능과 검증 성능의 절대 격차도 같이 봤습니다. 격차가 크면 데이터를 늘리거나 정규화를 강화하고, 둘 다 낮으면 모델이 부족한 것이라 반대로 용량을 키웠습니다.

**꼬리질문:** 검증 손실이 오르기 전에 멈추는 조기종료를 쓰면, 그 검증 데이터는 이미 오염된 것 아닌가요?

#### Q003. L1과 L2 정규화의 차이를 설명해 주세요. 🟢

**의도:** 정의를 아는지가 아니라, **왜** L1이 변수를 0으로 만드는지 기하학적으로 이해하는지 본다.

**답변:** L1은 계수 절댓값의 합에, L2는 계수 제곱합에 벌점을 줍니다. 결과적으로 L1은 일부 계수를 정확히 0으로 만들어 변수 선택 효과가 있고, L2는 계수를 전반적으로 작게 줄이지만 0으로 만들지는 않습니다. 이유는 제약 영역의 모양입니다. L1의 제약 영역은 마름모라 축 위의 꼭짓점에서 손실 등고선과 만나기 쉬운데, 그 지점이 바로 계수가 0인 지점입니다. L2는 원이라 꼭짓점이 없어 축에 정확히 닿기 어렵습니다.

**꼬리질문:** 변수들 사이에 상관이 아주 높을 때는 L1과 L2 중 어느 쪽이 낫습니까?

#### Q004. 랜덤 포레스트에서 변수를 무작위로 고르는 이유가 무엇입니까? 🟡

**의도:** 배깅과 랜덤 포레스트의 차이를 정확히 아는지, 앙상블의 분산 감소 원리를 이해하는지 본다.

**답변:** 트리들끼리 서로 닮지 않게 만들기 위해서입니다. 상관이 ρ인 예측을 B개 평균하면 분산이 ρσ² + (1−ρ)σ²/B가 됩니다. 트리를 아무리 많이 만들어도 뒷항만 0으로 가고 앞항의 ρσ²는 남습니다. 그런데 부트스트랩만 쓰면 강한 변수 하나에 모든 트리가 똑같이 의존해서 ρ가 높아집니다. 각 분할에서 변수 후보를 일부만 주면 트리들이 서로 다른 변수를 쓰게 되고 ρ가 떨어져서 평균의 분산이 실제로 줄어듭니다.

**꼬리질문:** 그럼 변수 후보 수를 아주 작게 하면 계속 좋아지나요?

#### Q005. 랜덤 포레스트와 그래디언트 부스팅 중 어느 것을 언제 쓰시겠습니까? 🟡

**의도:** 모델 선택의 근거를 성능 수치가 아니라 원리로 설명할 수 있는지 본다.

**답변:** 랜덤 포레스트는 분산을 줄이는 방법이고 부스팅은 편향을 줄이는 방법이라는 게 기준입니다. 빠르게 신뢰할 만한 기준선이 필요하거나, 하이퍼파라미터를 많이 만질 여유가 없거나, 학습을 병렬로 돌려야 하면 랜덤 포레스트를 씁니다. 정형 데이터에서 성능 상한을 끌어올려야 하면 부스팅을 씁니다. 대신 부스팅은 학습률과 트리 수, 깊이를 함께 조율해야 하고 과적합에 더 취약해서 검증 설계를 먼저 확실히 해 둡니다. 실제로는 랜덤 포레스트로 기준선을 잡고 부스팅으로 올려 보는 순서로 진행했습니다.

**꼬리질문:** 부스팅이 랜덤 포레스트보다 나쁘게 나오는 경우는 어떤 때입니까?

#### Q006. PCA와 PLS의 차이가 무엇입니까? 🟡

**의도:** 미세먼지 과제에서 PLS-DA를 쓴 근거를 물어보기 위한 사전 질문인 경우가 많다.

**답변:** PCA는 입력 데이터의 분산이 가장 큰 방향을 찾습니다. 목표 변수를 전혀 보지 않는 비지도 방법입니다. PLS는 입력과 출력의 공분산이 최대가 되는 방향을 찾습니다. 목표 변수를 보면서 축을 고릅니다. 그래서 PCA로 뽑은 상위 주성분이 예측에 별로 쓸모없는 경우가 생기는데, PLS는 그런 문제가 덜합니다. 변수가 관측치보다 많거나 변수 간 상관이 아주 높을 때 특히 유리합니다.

**꼬리질문:** 그럼 예측이 목적이면 항상 PCA보다 PLS가 낫습니까?

#### Q007. 미세먼지 과제에서 왜 PLS-DA를 쓰셨습니까? 🟡

**의도:** 도구를 관행으로 쓴 건지, 데이터 성질을 보고 고른 건지 확인한다.

**답변:** 영상 프레임에서 뽑은 특징들이 서로 상관이 매우 높았기 때문입니다. 인접한 프레임이나 인접한 픽셀 영역에서 나온 값들이라 거의 같은 정보를 담고 있었고, 확보한 관측치 수에 비해 변수 수가 많았습니다. 이런 조건에서 일반 회귀는 계수가 불안정해집니다. PLS는 상관이 높은 변수들을 소수의 잠재변수로 묶으면서 목표 변수와의 관계를 유지하기 때문에 이 상황에 맞았습니다. 분광 데이터에서 표준적으로 쓰이는 이유와 같은 맥락입니다.

**꼬리질문:** 릿지 회귀도 다중공선성에 강한데 그건 검토하셨나요?

#### Q008. 정확도가 99%인 모델을 가져왔다면 무엇을 먼저 확인하시겠습니까? 🟢

**의도:** 클래스 불균형을 즉시 의심하는지 본다. 가장 기본적인 함정 질문이다.

**답변:** 클래스 비율을 먼저 봅니다. 양성이 1%뿐이면 전부 음성이라고 답해도 정확도가 99%가 나오기 때문입니다. 혼동 행렬을 열어 클래스별 재현율을 확인하고, 불균형이면 PR-AUC나 F1으로 다시 평가합니다. 그다음으로 데이터 누수를 의심합니다. 목표 변수와 사실상 같은 정보를 담은 변수가 입력에 섞여 있거나, 전처리를 전체 데이터에 먼저 적용하고 나서 데이터를 나눈 경우가 흔합니다.

**꼬리질문:** 데이터 누수가 의심될 때 구체적으로 어떻게 찾아내십니까?

#### Q009. 불균형 데이터를 만나면 어떤 순서로 대응하시겠습니까? 🟡

**의도:** SMOTE부터 꺼내는지, 비용이 낮은 것부터 시도하는지 본다.

**답변:** 결정 임계값 조정을 먼저 합니다. 재학습이 필요 없고 비용이 0이라서, 여기서 원하는 정밀도-재현율 균형이 나오면 더 할 일이 없습니다. 그다음이 손실함수의 클래스 가중치나 Focal Loss입니다. 데이터를 건드리지 않으면서 학습 신호를 조정하는 방법입니다. 오버샘플링이나 SMOTE는 마지막에 고려합니다. 합성 샘플이 소수 클래스의 실제 분포를 왜곡할 수 있고, 검증 폴드에 잘못 적용하면 성능이 부풀려지기 때문입니다. 평가지표는 처음부터 PR-AUC와 클래스별 재현율로 바꿔 둡니다.

**꼬리질문:** 임계값은 어떤 기준으로 정하십니까?

#### Q010. MAE와 RMSE 중 어느 것을 쓰시겠습니까? 🟡

**의도:** 치수 측정 논문들의 평가지표 선택 근거를 확인한다.

**답변:** 오차의 성격에 따라 다릅니다. RMSE는 오차를 제곱하므로 큰 오차 하나가 전체 지표를 크게 흔듭니다. 큰 오차가 특히 위험한 상황이면 RMSE가 맞습니다. 반대로 대부분 잘 맞다가 가끔 크게 틀리는 경우, 예를 들어 키포인트 하나가 엉뚱한 곳에 잡히는 상황에서는 RMSE가 모델 전체를 과소평가하게 만듭니다. 치수 측정에서는 MAE를 주로 보고, 크기가 다른 부위를 비교할 때는 MAPE를 함께 봤습니다. 두 지표를 같이 보면 오차가 고르게 퍼져 있는지 한쪽에 몰려 있는지도 알 수 있습니다.

**꼬리질문:** MAPE의 단점은 무엇입니까?

#### Q011. R²가 낮게 나왔는데 모델이 나쁜 게 아닐 수도 있습니까? 🔴

**의도:** 지표를 기계적으로 읽는지, 데이터 구성까지 고려하는지 본다.

**답변:** 그럴 수 있습니다. R²는 평균으로 예측했을 때 대비 얼마나 나은지를 보는 지표라, 분모에 실제값의 분산이 들어갑니다. 측정 대상 집단이 균질해서 실제 편차가 작으면 분모가 작아지고, 같은 절대 오차라도 R²가 낮게 나옵니다. 예를 들어 비슷한 체형만 모은 데이터로 평가하면 절대 오차가 작아도 R²는 나쁘게 보입니다. 그래서 R² 하나로 판단하지 않고 MAE 같은 절대 지표를 함께 보고, 대상 집단의 분산이 실제 사용 환경과 비슷한지도 확인했습니다.

**꼬리질문:** 그럼 평가 데이터를 일부러 다양하게 구성하면 R²를 올릴 수 있다는 뜻인데, 그건 조작 아닙니까?

#### Q012. p-value가 0.03이 나왔습니다. 이걸 어떻게 해석하시겠습니까? 🔴

**의도:** 통계 전공자에게 던지는 검증 질문이다. 여기서 틀리면 전공에 대한 신뢰가 흔들린다.

**답변:** 귀무가설이 참이라고 가정했을 때, 관측된 것만큼 극단적인 결과가 나올 확률이 3%라는 뜻입니다. 귀무가설이 참일 확률이 3%라는 뜻이 아닙니다. 조건의 방향이 반대입니다. 그리고 유의하다는 것이 효과가 크다는 뜻도 아닙니다. 표본이 아주 크면 실용적으로 의미 없는 차이도 유의하게 나오기 때문에, 효과크기와 신뢰구간을 반드시 함께 봅니다. 실무에서는 이 차이가 현장에서 의미 있는 크기인지를 먼저 물어보는 편입니다.

**꼬리질문:** 여러 모델을 동시에 비교하면 p-value를 어떻게 다뤄야 합니까?

#### Q013. 교차검증에서 데이터 누수가 생기는 경우를 말씀해 주세요. 🟡

**의도:** 검증 설계를 직접 해 본 사람인지 확인한다.

**답변:** 세 가지를 주로 봅니다. 첫째, 전처리 순서입니다. 표준화나 결측 대치를 전체 데이터에 먼저 적용하고 폴드를 나누면 검증 폴드의 통계량이 학습에 들어갑니다. 전처리는 폴드 안에서 학습 데이터로만 적합시켜야 합니다. 둘째, 그룹 구조입니다. 같은 개체나 같은 촬영 세션에서 나온 샘플이 학습과 검증에 나뉘어 들어가면 사실상 답을 보고 맞히는 것이 됩니다. 이럴 때는 그룹 단위로 나눕니다. 셋째, 시간 순서입니다. 시계열은 무작위로 섞으면 미래 정보가 과거 학습에 들어가므로 시간 순 분할을 씁니다.

**꼬리질문:** 가스배관 과제에서는 어떤 단위로 나누셨습니까?

#### Q014. 파생변수를 만들 때 어떤 기준으로 고르십니까? 🟡

**의도:** 되는 대로 만드는지, 문제 구조에서 출발하는지 본다.

**답변:** 먼저 물리적으로 무엇이 신호를 만드는지 생각합니다. 가스배관 과제에서는 접합부나 만곡부를 지날 때 센서 값의 절대 크기보다 국소적인 변동이 달라진다고 봤습니다. 그래서 구간 내 분산, 최대-최소 차이, 행 간 변화량처럼 변동을 요약하는 변수를 만들었습니다. 그다음에 실제로 그 변수가 클래스별로 분포가 다른지 확인하고, 모델에 넣어 중요도와 성능 기여를 봤습니다. 만들어 놓고 성능이 오르는지만 보는 방식은 우연히 맞는 변수를 남기게 되어 피했습니다.

**꼬리질문:** 파생변수를 늘리면 차원이 커지는데 그 문제는 어떻게 다루셨습니까?

#### Q015. 데이터가 아주 적을 때는 어떻게 접근하십니까? 🟡

**의도:** 딥러닝만 아는 사람인지, 상황에 따라 도구를 바꾸는지 본다.

**답변:** 모델 용량을 줄이는 쪽으로 먼저 갑니다. 파라미터가 많은 신경망보다 정규화가 들어간 선형모델이나 얕은 트리 앙상블이 안정적입니다. 검증은 K를 키운 교차검증이나 반복 교차검증으로 하고, 단일 분할 성능은 믿지 않습니다. 데이터를 늘릴 수 있으면 증강을 쓰되, 증강이 실제 변동을 반영하는지 확인합니다. 사전학습 모델이 있으면 전이학습으로 특징 추출기만 가져오고 마지막 층만 학습시키는 방식도 씁니다. 치과 영상 논문에서 생성모델로 데이터를 만든 것도 같은 문제의식에서 나온 접근입니다.

**꼬리질문:** 생성한 데이터로 학습하면 성능이 진짜 오르는 건지 어떻게 검증합니까?
