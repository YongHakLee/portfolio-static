# 기초개념 5 — 생성모델: GAN · Diffusion

---

## 이 문서를 읽는 법

논문 두 편이 여기에 걸린다. **T02(교신저자, 전후면 의류 생성)** 는 확산모델이고, **T08(치과 영상 데이터 생성)** 은 GAN이다. 교신저자 논문이 확산모델이라는 점이 중요하다. 면접관은 교신저자 논문을 "이 사람이 연구 방향을 정한 논문"으로 읽고 가장 깊이 파고든다.

이 영역에서 준비해야 할 축은 세 가지다.

첫째, **GAN과 확산모델의 차이와 선택 근거.** 두 논문이 서로 다른 방법을 쓰기 때문에 "왜 이건 GAN이고 저건 확산모델입니까"가 자연스럽게 나온다. 시기 차이(2023 대 2025)도 답의 일부지만, 그것만 말하면 유행을 따라간 것으로 들린다. 각 과제의 요구가 무엇이었는지로 답해야 한다.

둘째, **생성 데이터로 학습하는 것의 정당성.** T08의 핵심 주장이 "GAN으로 만든 데이터가 분할 성능을 올린다"인데, 여기에는 "가짜 데이터로 학습하면 가짜를 배우는 것 아닌가"라는 근본적 반문이 따라온다. 이에 대한 답을 준비해야 한다.

셋째, **생성 품질을 어떻게 평가하는가.** 생성 결과는 정답이 없어서 평가가 어렵다. FID가 무엇을 재는지, 그 한계가 무엇인지 알아야 한다.

순서는 **GAN 계열 → 확산모델 계열 → 조건부 제어 → 평가와 활용** 이다. 급하면 **GAN의 원리 · DDPM · 확산모델을 쓰는 이유 · FID · 합성 데이터** 다섯 개를 먼저 본다.

## 개념 목록

### 생성모델이란

**직관**

판별모델은 "이 이미지가 고양이인가"를 답한다. 생성모델은 "고양이 이미지를 하나 그려 봐"에 답한다. 전자는 데이터가 주어졌을 때 레이블의 확률을 배우고, 후자는 **데이터 자체의 분포를 배운다.**

분포를 배운다는 것은 "어떤 이미지가 그럴듯하고 어떤 이미지가 아닌가"를 안다는 뜻이다. 그 분포에서 표본을 뽑으면 새로운 이미지가 나온다.

**정의**

| 구분 | 학습 대상 | 예 |
|------|-----------|-----|
| 판별모델 | `P(y \| x)` — 입력이 주어졌을 때 레이블의 확률 | 분류기, 검출기 |
| 생성모델 | `P(x)` 또는 `P(x \| y)` — 데이터 자체의 분포 | GAN, VAE, 확산모델 |

**생성모델의 계보**

| 모델군 | 원리 | 장단점 |
|--------|------|--------|
| VAE | 잠재변수로 인코딩·디코딩, 변분 추론 | 학습 안정. 결과가 흐릿함 |
| GAN | 생성기와 판별기의 적대적 경쟁 | 선명함. 학습 불안정, 모드 붕괴 |
| Flow 기반 | 가역 변환으로 정확한 우도 계산 | 우도 계산 가능. 구조 제약이 큼 |
| 자기회귀 | 픽셀·토큰을 순차 생성 | 우도 정확. 느림 |
| **확산모델** | 노이즈를 점진적으로 제거 | 품질·다양성 우수. 샘플링이 느림 |

**면접 포인트**

**"왜 생성모델이 필요한가"** 라는 질문에는 세 갈래로 답할 수 있다. 데이터가 부족할 때 채우기 위해(T08), 사람이 원하는 이미지를 만들기 위해(T02), 그리고 데이터의 구조를 이해하기 위해서다. 자기 논문이 앞의 두 경우에 각각 해당하므로 이 구도로 답하면 자연스럽다.

### GAN의 원리

**직관**

위조지폐범과 경찰의 경쟁에 비유한다. 위조범(생성기)은 진짜 같은 지폐를 만들려 하고, 경찰(판별기)은 진짜와 가짜를 구별하려 한다. 둘이 계속 경쟁하면 위조범의 실력이 올라가 결국 구별할 수 없는 지폐를 만든다.

**정의**

생성기 G와 판별기 D가 서로 반대되는 목표로 학습하는 구조다. G는 무작위 잡음 z를 받아 가짜 데이터를 만들고, D는 입력이 진짜인지 가짜인지 판정한다.

**핵심 수식**

원 논문의 목적함수:

```
min_G max_D  V(D, G) = E_x[log D(x)] + E_z[log(1 - D(G(z)))]
```

- `x`: 실제 데이터
- `z`: 잠재 벡터(보통 정규분포에서 추출)
- `G(z)`: 생성된 가짜 데이터
- `D(·)`: 진짜일 확률 (0~1)

**읽는 법**

- D는 이 값을 **최대화**하려 한다. 진짜에 대해 `D(x)`를 1로(앞항 최대), 가짜에 대해 `D(G(z))`를 0으로(뒷항 최대) 만들려 한다
- G는 이 값을 **최소화**하려 한다. `D(G(z))`를 1로 만들어 뒷항을 최소화한다

**실무적 수정**

원래 G의 손실 `log(1 - D(G(z)))`는 학습 초기에 기울기가 매우 작다. G가 형편없어서 `D(G(z))`가 0에 가까우면 이 항의 기울기가 거의 0이다. 그래서 실제로는 G가 `log D(G(z))`를 최대화하도록 바꿔 쓴다(non-saturating loss).

**학습 절차**

```
반복:
  1. D를 k번 갱신: 진짜 배치와 가짜 배치로 판별 손실 최소화
  2. G를 1번 갱신: D를 속이는 방향으로
```

**면접 포인트**

**균형이 핵심**이라는 점을 말할 수 있어야 한다. D가 너무 강하면 G에게 전달되는 기울기가 사라지고, D가 너무 약하면 G가 대충 만들어도 통과한다. 학습률과 갱신 횟수를 조율해 둘의 실력을 비슷하게 유지해야 한다. 이 균형 잡기의 어려움이 GAN의 근본적 불편함이고, 확산모델이 각광받은 이유 중 하나다.

### GAN의 학습 불안정성과 모드 붕괴

**직관**

**모드 붕괴(mode collapse)** 는 생성기가 몇 가지 결과만 반복해서 만드는 현상이다. 판별기를 속이는 이미지 하나를 찾으면 그것만 계속 만드는 게 손해가 없기 때문이다. 손글씨 숫자를 생성해야 하는데 3만 계속 그리는 상황이다.

**주요 문제**

| 문제 | 현상 | 원인 |
|------|------|------|
| 모드 붕괴 | 다양성 없이 몇 가지만 생성 | G가 D를 속이는 특정 해에 고착 |
| 기울기 소실 | G가 학습되지 않음 | D가 너무 강해짐 |
| 진동 | 손실이 수렴하지 않고 요동 | 두 목표가 상충하는 미니맥스 게임의 본질 |
| 평가 어려움 | 손실값이 품질을 반영하지 않음 | 상대적 경쟁이라 절대 기준이 없음 |

**대응 기법**

| 기법 | 방법 |
|------|------|
| WGAN | Wasserstein 거리로 목적함수 교체. 기울기가 항상 유의미 |
| WGAN-GP | 립시츠 제약을 기울기 벌점으로 구현 |
| Spectral Normalization | 판별기 가중치의 스펙트럼 노름을 제한 |
| 미니배치 판별 | 배치 내 다양성을 판별기가 보게 함 |
| 특징 매칭 | 판별기 중간 특징의 통계를 맞춤 |
| 2-Timescale (TTUR) | G와 D에 다른 학습률 사용 |

**면접 포인트**

**"GAN 학습이 안 될 때 무엇을 확인하는가"** 라는 실무 질문에 순서를 갖고 답한다. 먼저 생성 이미지를 직접 눈으로 본다(손실값만으로는 알 수 없다). 다양성이 없으면 모드 붕괴, 노이즈만 나오면 G가 학습되지 않는 것이다. 그다음 D와 G의 손실 추이를 비교해 어느 쪽이 압도하는지 본다. D가 손실 0에 붙어 있으면 D가 너무 강한 것이므로 D의 학습률을 낮추거나 갱신 횟수를 줄인다.

**손실값이 품질을 반영하지 않는다**는 점도 중요하다. 지도학습에서는 검증 손실이 떨어지면 좋아진 것이지만, GAN은 상대적 경쟁이라 손실이 낮다고 좋은 게 아니다. 그래서 FID 같은 별도 지표와 육안 확인이 필수다.

### 조건부 GAN

**직관**

기본 GAN은 무작위 잡음에서 아무 이미지나 만든다. 무엇을 만들지 지정할 수 없다. 조건부 GAN은 생성기와 판별기 모두에 **조건**을 함께 넣어, "숫자 7을 그려라"처럼 지정할 수 있게 한다.

**정의**

클래스 레이블, 텍스트, 다른 이미지 등의 조건 y를 G와 D 양쪽에 입력한다.

**핵심 수식**

```
min_G max_D  E_x[log D(x|y)] + E_z[log(1 - D(G(z|y)|y))]
```

- `y`: 조건. 클래스 원핫 벡터, 텍스트 임베딩, 세그멘테이션 맵 등

**조건 주입 방식**

| 방식 | 설명 |
|------|------|
| 입력 결합 | 조건 벡터를 잡음과 이어 붙임 |
| 조건부 배치 정규화 | 정규화의 스케일·시프트를 조건으로 생성 |
| 투영 판별기 | 판별기에서 조건과 특징의 내적을 더함 |
| 교차 어텐션 | 조건을 어텐션의 key·value로 사용 (확산모델에서 표준) |

**면접 포인트**

**조건부 생성이 없으면 응용이 안 된다**는 점을 짚는다. 데이터 증강 목적으로 생성하려면 "어떤 클래스의 데이터"를 만들어야 하고, 의류 생성이라면 "이런 속성의 옷"을 만들어야 한다. 무작위 생성만으로는 쓸모가 제한적이다. T08과 T02 모두 조건부 생성이다.

### pix2pix

**직관**

이미지를 이미지로 번역한다. 스케치를 사진으로, 흑백을 컬러로, 세그멘테이션 맵을 실사로 바꾸는 식이다. 조건이 이미지인 조건부 GAN이다.

**정의**

**쌍을 이룬(paired)** 데이터로 학습하는 이미지 변환 모델이다. 입력 이미지와 출력 이미지가 정확히 대응하는 데이터셋이 필요하다.

**구조**

| 구성 | 내용 |
|------|------|
| 생성기 | U-Net (스킵 연결로 입력의 구조를 보존) |
| 판별기 | PatchGAN — 전체가 아니라 N×N 패치 단위로 진짜·가짜 판정 |
| 손실 | 적대적 손실 + L1 손실 |

**핵심 수식**

```
L = L_GAN(G, D) + λ · L_L1(G)
L_L1 = E[‖ y - G(x) ‖₁]
```

- `λ`: L1 항의 가중치. 보통 100
- L1 손실이 "정답과 비슷하게" 만들고, 적대적 손실이 "선명하게" 만든다

**PatchGAN을 쓰는 이유**: L1 손실이 이미 저주파(전체적인 구조)를 담당하므로, 판별기는 고주파(질감, 세부)만 보면 된다. 패치 단위로 판정하면 파라미터가 적고 어떤 크기의 이미지에도 적용된다.

**면접 포인트**

**L1과 적대적 손실을 함께 쓰는 이유**가 좋은 질문이다. L1만 쓰면 여러 가능한 출력의 평균이 나와 흐릿해진다. 적대적 손실만 쓰면 선명하지만 입력과 무관한 그럴듯한 이미지가 나올 수 있다. 둘을 합치면 "입력에 충실하면서 선명한" 결과가 나온다.

이 구도는 확산모델에도 그대로 이어진다. 재구성 손실과 사실성 제약을 함께 두는 발상이다.

### CycleGAN

**직관**

pix2pix는 입력과 출력이 짝지어진 데이터가 필요한데, 그런 데이터를 구하기 어려운 경우가 많다. 말 사진과 그에 정확히 대응하는 얼룩말 사진 쌍은 존재하지 않는다.

CycleGAN은 짝 없는 데이터로 학습한다. 핵심 아이디어는 **순환 일관성**이다. 말을 얼룩말로 바꿨다가 다시 말로 되돌렸을 때 원래 말이 나와야 한다는 제약을 건다.

**정의**

두 도메인 사이의 변환기 두 개(G: A→B, F: B→A)와 판별기 두 개를 함께 학습하며, 순환 일관성 손실로 제약한다.

**핵심 수식**

```
L_cyc = E_a[‖ F(G(a)) - a ‖₁] + E_b[‖ G(F(b)) - b ‖₁]
```

- `G(a)`: A 도메인 이미지를 B로 변환
- `F(G(a))`: 다시 A로 되돌림. 원래 `a`와 같아야 한다

전체 손실은 두 방향의 적대적 손실에 순환 일관성 손실, 그리고 필요하면 항등 손실을 더한다.

**한계**

- 형태를 크게 바꾸는 변환(개→고양이)은 잘 안 된다. 순환 일관성이 구조를 보존하도록 압박하기 때문이다
- 순환 일관성만으로는 의미적 대응이 보장되지 않는다. 정보를 숨겨서(steganography) 순환 조건만 만족시키는 해가 존재한다

**면접 포인트**

T02 논문이 전면과 후면의 **일관성**을 다룬다는 점에서 개념적 연결이 있다. 다만 CycleGAN의 순환 일관성과 T02의 전후면 속성 일관성은 다른 문제다. 전자는 변환의 가역성, 후자는 두 뷰가 같은 대상을 나타내야 한다는 제약이다. 이 구분을 명확히 해 두면 혼동하지 않는다.

### StyleGAN 계열

**직관**

기존 GAN은 잡음 벡터를 그대로 생성기에 넣었는데, StyleGAN은 잡음을 먼저 **중간 잠재 공간**으로 매핑하고, 그 값으로 각 층의 정규화 파라미터를 조절한다. 결과적으로 "머리 색", "포즈", "나이" 같은 속성이 층별로 분리되어 개별 조작이 가능해진다.

**정의**

| 버전 | 핵심 |
|------|------|
| StyleGAN | 매핑 네트워크 + AdaIN으로 층별 스타일 주입 |
| StyleGAN2 | 물방울 아티팩트 제거, 가중치 변조 방식 개선 |
| StyleGAN3 | 앨리어싱 제거로 회전·이동에 일관된 생성 |

**AdaIN (Adaptive Instance Normalization)**

```
AdaIN(x, y) = y_s · (x - μ(x)) / σ(x) + y_b
```

- `μ(x), σ(x)`: 특징 맵의 채널별 평균·표준편차
- `y_s, y_b`: 스타일 벡터에서 나온 스케일과 바이어스

**면접 포인트**

**잠재 공간의 분리(disentanglement)** 개념이 중요하다. 잘 분리된 잠재 공간에서는 한 방향으로 움직이면 하나의 속성만 바뀐다. 이것이 속성 편집을 가능하게 하고, T02처럼 "속성이 일관된" 이미지를 만들어야 하는 과제와 개념적으로 이어진다.

---

### 확산모델의 직관

**직관**

깨끗한 사진에 노이즈를 조금씩 계속 더하면 결국 완전한 잡음이 된다. 이 과정은 쉽고 계산도 간단하다. 확산모델은 **이 과정을 거꾸로 돌리는 법을 배운다.** 잡음에서 시작해 조금씩 노이즈를 걷어 내면 이미지가 나타난다.

GAN이 "한 번에 이미지를 만들어 내는" 방식이라면, 확산모델은 "수십~수백 단계에 걸쳐 조금씩 다듬어 가는" 방식이다. 각 단계의 과제가 훨씬 쉽기 때문에 학습이 안정적이다.

**GAN과의 근본적 차이**

| 항목 | GAN | 확산모델 |
|------|-----|----------|
| 학습 | 두 망의 적대적 경쟁 | 단일 망의 지도학습 (노이즈 예측) |
| 안정성 | 불안정. 모드 붕괴 | 안정 |
| 다양성 | 제한적 | 우수 |
| 생성 속도 | 1회 순전파 (빠름) | 수십~수천 단계 (느림) |
| 조건 제어 | 제한적 | 유연 (분류기 프리 가이던스, ControlNet 등) |
| 학습 신호 | 판별기의 판정 | 명확한 회귀 목표 (더한 노이즈) |

**면접 포인트**

**"확산모델의 학습이 왜 안정적인가"** 를 한 문장으로 설명할 수 있어야 한다. **"목표가 명확한 지도학습이기 때문"** 이다. 어떤 노이즈를 더했는지 알고 있으므로, 그 노이즈를 맞히는 회귀 문제가 된다. 정답이 있는 문제라 판별기와의 균형 같은 것을 신경 쓸 필요가 없다.

---

### DDPM의 순방향과 역방향 과정

**직관**

순방향은 이미지를 망가뜨리는 과정이고, 역방향은 복원하는 과정이다. 순방향은 학습이 필요 없고(그냥 노이즈를 더하면 된다), 역방향만 신경망이 배운다.

**순방향 과정 (forward / diffusion)**

각 단계에서 조금씩 가우시안 노이즈를 더한다.

```
q(x_t | x_{t-1}) = N(x_t ;  √(1-β_t) · x_{t-1},  β_t · I)
```

- `x_0`: 원본 이미지
- `x_t`: t단계까지 노이즈가 더해진 이미지
- `β_t`: t단계의 노이즈 크기. 작은 값(예: 0.0001~0.02)
- `N(·; μ, Σ)`: 평균 μ, 공분산 Σ의 정규분포

**임의 시점으로 한 번에 건너뛰기**

여러 단계를 거치지 않고 `x_0`에서 `x_t`를 바로 만들 수 있다는 것이 계산상의 핵심이다.

```
x_t = √(ᾱ_t) · x_0 + √(1 - ᾱ_t) · ε,    ε ~ N(0, I)
```

- `α_t = 1 - β_t`
- `ᾱ_t = α_1 · α_2 · ... · α_t` (누적곱)
- `ε`: 표준정규분포에서 뽑은 노이즈

**읽는 법**: `√(ᾱ_t)`가 원본의 비중, `√(1-ᾱ_t)`가 노이즈의 비중이다. t가 커질수록 `ᾱ_t`가 0에 가까워져 노이즈만 남는다.

**역방향 과정 (reverse / denoising)**

신경망 `ε_θ`가 "이 이미지에 어떤 노이즈가 섞여 있는가"를 예측한다.

```
L_simple = E_{x_0, ε, t} [ ‖ ε - ε_θ(x_t, t) ‖² ]
```

- `ε`: 실제로 더한 노이즈 (정답)
- `ε_θ(x_t, t)`: 신경망의 예측
- `t`: 현재 단계. 신경망에 함께 입력한다(시간 임베딩)

**이것이 그냥 MSE 회귀라는 점**이 확산모델 학습이 안정적인 이유다.

**샘플링**

```
x_{t-1} = (1/√α_t) · ( x_t - (β_t / √(1-ᾱ_t)) · ε_θ(x_t, t) ) + σ_t · z
```

- `z ~ N(0, I)`: 마지막 단계를 제외하고 더하는 무작위성
- `σ_t`: 샘플링 노이즈 크기

이 과정을 T단계(보통 1000)부터 0까지 반복하면 이미지가 나온다.

**면접 포인트**

**"학습할 때 1000단계를 다 거치는가"** 라는 질문이 나올 수 있다. 답은 아니다. 학습 시에는 t를 무작위로 하나 뽑아 그 시점의 노이즈만 예측하게 한다. 위의 "한 번에 건너뛰기" 공식 덕분에 가능하다. **샘플링할 때만** 순차적으로 T단계를 밟는다. 그래서 학습은 빠르고 생성이 느리다.

가속 기법도 알아 둔다. DDIM은 결정론적 샘플링으로 단계를 20~50으로 줄이고, 증류(distillation) 기법은 몇 단계까지 줄인다. Flux 같은 최신 모델은 flow matching 기반으로 더 적은 단계에서 동작한다. T02가 flux를 쓴다면 이 맥락을 알아야 한다.

### 노이즈 스케줄

**직관**

각 단계에서 노이즈를 얼마나 더할지 정하는 규칙이다. 처음부터 확 더하면 정보가 너무 빨리 사라지고, 너무 조금씩 더하면 단계가 많이 필요하다.

**주요 스케줄**

| 스케줄 | 특징 |
|--------|------|
| Linear | `β_t`를 선형으로 증가. 원 DDPM |
| Cosine | 후반부에 천천히 망가뜨림. 저해상도에서 성능 개선 |
| Sigmoid | 중간 구간에 집중 |

**왜 중요한가**

`ᾱ_t`의 변화 곡선이 "어느 단계에서 무엇을 배우는가"를 결정한다. 노이즈가 적은 단계(t가 작을 때)에서는 세부 질감을, 노이즈가 많은 단계에서는 전체 구조를 배운다. 스케줄이 나쁘면 특정 정보를 배우는 단계가 부족해진다.

**면접 포인트**

Linear 스케줄이 저해상도에서 후반부에 정보를 너무 빨리 파괴한다는 지적이 있었고, 그래서 Cosine 스케줄이 제안됐다. 이 정도 맥락을 알면 충분하다. 실무에서는 라이브러리 기본값을 쓰는 경우가 많으므로, "기본 스케줄을 썼고 이런 이유로 그게 적절했다"는 답도 정직하다.

### 잠재 확산모델 (Latent Diffusion)

**직관**

512×512 이미지의 픽셀 공간에서 확산 과정을 돌리면 계산이 엄청나다. 잠재 확산모델은 먼저 오토인코더로 이미지를 작은 잠재 표현(예: 64×64)으로 압축하고, **그 잠재 공간에서 확산 과정을 돌린다.** 마지막에 디코더로 다시 이미지로 펼친다.

계산량이 수십 배 줄어드는데, 인지적으로 중요하지 않은 고주파 세부는 오토인코더가 담당하고 확산모델은 의미적 구조에 집중하기 때문에 품질 손실이 크지 않다.

**정의**

Stable Diffusion의 기반 구조다. 세 부분으로 이뤄진다.

```
VAE 인코더 → 잠재 공간에서의 U-Net 확산 → VAE 디코더
                      ↑
              텍스트 인코더(CLIP)의 조건
```

**면접 포인트**

**"확산모델이 느리다면서 어떻게 실용화됐나"** 에 대한 답이 이것이다. 잠재 공간 압축과 샘플링 단계 축소(DDIM 등)가 결합해 실용 수준이 됐다.

T02 논문이 이미지 생성에 쓰는 모델의 구조를 이해하려면 이 개념이 필요하다. 논문에서 언급하는 flux 계열도 잠재 공간에서 동작한다.

---

### 텍스트 조건부 생성과 CLIP

**직관**

"빨간 원피스"라는 문장으로 이미지를 만들려면, 텍스트와 이미지를 같은 공간에서 비교할 수 있어야 한다. CLIP은 이미지-텍스트 쌍 수억 개로 학습해, **같은 의미의 이미지와 텍스트가 가까운 벡터가 되도록** 만든 모델이다.

**정의**

CLIP(Contrastive Language-Image Pre-training)은 이미지 인코더와 텍스트 인코더를 대조 학습으로 함께 훈련한다. 배치 안에서 올바른 (이미지, 텍스트) 쌍의 유사도는 높이고 나머지는 낮춘다.

**핵심 수식**

대조 손실(InfoNCE 형태):

```
L = -log( exp(sim(Iᵢ, Tᵢ)/τ) / Σⱼ exp(sim(Iᵢ, Tⱼ)/τ) )
```

- `sim`: 코사인 유사도
- `Iᵢ, Tᵢ`: i번째 쌍의 이미지·텍스트 임베딩
- `τ`: 온도 파라미터

**분류기 프리 가이던스 (Classifier-Free Guidance)**

텍스트 조건을 얼마나 강하게 따를지 조절하는 기법이다. 조건이 있을 때와 없을 때의 예측을 모두 구하고, 그 차이를 증폭한다.

```
ε̃ = ε_θ(x_t, ∅) + w · ( ε_θ(x_t, c) - ε_θ(x_t, ∅) )
```

- `c`: 조건(텍스트)
- `∅`: 조건 없음
- `w`: 가이던스 스케일. 크면 프롬프트를 강하게 따르지만 다양성과 자연스러움이 떨어진다

**면접 포인트**

**가이던스 스케일의 트레이드오프**는 실무 감각을 보여 주는 좋은 소재다. w를 키우면 프롬프트에 충실해지지만 채도가 과해지고 부자연스러워진다. 보통 7~8 근처를 쓴다.

T02가 텍스트로부터 이미지를 만드는 파이프라인이므로, 프롬프트가 정교할수록 결과가 좋아진다는 것이 LLM으로 상세한 설명을 먼저 생성하는 1단계의 근거다. 이 논리 연결을 설명할 수 있어야 한다.

### ControlNet

**직관**

텍스트만으로는 "이 자세로", "이 윤곽선을 따라"를 지시할 수 없다. ControlNet은 사전학습된 확산모델의 가중치를 **복사해 옆에 붙이고**, 그 복사본만 학습시켜 엣지 맵·자세·깊이 맵 같은 공간적 조건을 주입한다.

원본 모델은 얼어 있어서 기존 성능이 망가지지 않고, 추가된 경로는 **제로 초기화된 합성곱**으로 연결되어 학습 초기에 아무 영향도 주지 않다가 점진적으로 개입한다.

**정의**

사전학습된 확산 U-Net의 인코더 블록을 복제해 조건 입력을 처리하고, 제로 합성곱(zero convolution)을 통해 원본 디코더에 더하는 구조다.

**제로 초기화의 의미**

```
y = F(x) + Z( C(c) )
```

- `F`: 얼어 있는 원본 블록
- `C`: 학습되는 복제 블록
- `Z`: 가중치가 0으로 초기화된 1×1 합성곱

학습 시작 시 `Z`의 출력이 0이므로 원본 모델과 동일하게 동작한다. 유해한 노이즈가 사전학습된 표현을 망가뜨리는 것을 막는다.

**조건 유형**

Canny 엣지, 소벨 엣지, 자세(OpenPose), 깊이 맵, 세그멘테이션 맵, 스크리블, 법선 맵 등.

**면접 포인트**

**"전면과 후면의 구조적 일관성을 어떻게 유지하나"** 라는 질문에 ControlNet 계열 기법이 답이 될 수 있다. 후면을 생성할 때 전면의 실루엣이나 구조를 조건으로 주면 형태가 어긋나지 않는다. T02 논문에서 실제로 어떤 방법을 썼는지는 원문에서 확인해야 하지만, 이 개념적 배경을 알고 있으면 논문의 선택을 평가할 수 있다.

---

### LoRA와 파인튜닝

**직관**

거대한 모델 전체를 다시 학습시키려면 GPU 메모리와 시간이 엄청나게 든다. LoRA는 원래 가중치는 그대로 두고, **작은 저계수 행렬 두 개만 추가로 학습한다.** 파라미터가 원본의 1% 미만이라 훨씬 가볍다.

**정의**

가중치 갱신량 ΔW를 두 개의 낮은 계수 행렬의 곱으로 근사한다.

**핵심 수식**

```
W' = W + ΔW = W + B·A
```

- `W`: 원본 가중치 (d × k), 얼어 있음
- `A`: (r × k) 행렬
- `B`: (d × r) 행렬
- `r`: 계수(rank). 보통 4~64. `r << min(d, k)`

파라미터 수가 `d×k`에서 `r×(d+k)`로 줄어든다. d=k=1000, r=8이면 100만 개에서 1.6만 개로 준다.

**관련 기법**

| 기법 | 설명 |
|------|------|
| LoRA | 저계수 행렬 추가 |
| QLoRA | 원본을 4비트로 양자화한 채 LoRA 학습 |
| DreamBooth | 특정 대상을 몇 장의 이미지로 학습시켜 생성 가능하게 |
| Textual Inversion | 새 개념을 나타내는 토큰 임베딩만 학습 |
| Adapter | 층 사이에 작은 병목 모듈 삽입 |

**면접 포인트**

**"의류 도메인에 맞추려면 어떻게 하나"** 라는 질문에 LoRA가 자연스러운 답이다. 범용 확산모델은 일반적인 이미지를 잘 만들지만 특정 의류 스타일이나 촬영 방식에는 맞지 않는다. 전체 파인튜닝은 자원이 많이 들고 과적합 위험도 크므로, 소량의 도메인 데이터로 LoRA를 학습시키는 것이 실용적이다.

### 인페인팅과 이미지 편집

**직관**

이미지의 일부만 다시 그리는 것이다. 마스크로 영역을 지정하고, 그 부분만 조건에 맞게 생성하면서 나머지는 보존한다.

**방법**

| 방법 | 원리 |
|------|------|
| 마스크 기반 재노이즈 | 매 샘플링 단계에서 마스크 밖은 원본의 노이즈 버전으로 대체 |
| 인페인팅 전용 모델 | 마스크와 원본을 입력 채널로 받아 학습 |
| SDEdit | 원본에 노이즈를 일부만 더한 뒤 거기서 역과정 시작 |
| img2img | 원본을 초기값으로 삼아 강도(strength)만큼만 변형 |

**면접 포인트**

**전면 이미지에서 후면을 만드는 과제**는 인페인팅과 성격이 다르다. 인페인팅은 주변 맥락으로 빈 곳을 채우는 것인데, 후면 생성은 보이지 않는 반대편을 추론하는 것이다. 정보가 원본에 없으므로 사전 지식(옷은 대체로 이런 구조다)에 의존해야 한다. T02가 왜 어려운 문제인지를 설명할 때 이 구분이 유용하다.

### 생성 품질 평가 (FID·LPIPS·SSIM·PSNR)

**직관**

생성 결과에는 정답이 없다. "이 이미지가 얼마나 좋은가"를 숫자로 재기 어렵다. 그래서 여러 지표를 조합하고 육안 평가를 함께 한다.

**주요 지표**

| 지표 | 재는 것 | 방향 | 정답 필요 |
|------|---------|------|-----------|
| FID | 생성 이미지 분포와 실제 분포의 거리 | 낮을수록 좋음 | 실제 이미지 집합 |
| IS (Inception Score) | 생성 이미지의 선명도와 다양성 | 높을수록 좋음 | 불필요 |
| LPIPS | 지각적 유사도 (신경망 특징 기반) | 낮을수록 유사 | 쌍 필요 |
| SSIM | 구조적 유사도 (밝기·대비·구조) | 높을수록 유사 | 쌍 필요 |
| PSNR | 픽셀 단위 오차 기반 | 높을수록 유사 | 쌍 필요 |
| CLIP Score | 텍스트-이미지 정합도 | 높을수록 좋음 | 텍스트 |

**핵심 수식**

FID:

```
FID = ‖μ_r - μ_g‖² + Tr( Σ_r + Σ_g - 2(Σ_r Σ_g)^(1/2) )
```

- `μ_r, Σ_r`: 실제 이미지들의 Inception 특징의 평균과 공분산
- `μ_g, Σ_g`: 생성 이미지들의 것
- 두 분포를 가우시안으로 가정하고 Wasserstein-2 거리를 계산한다

SSIM:

```
SSIM(x,y) = [(2μ_xμ_y + c₁)(2σ_xy + c₂)] / [(μ_x²+μ_y²+c₁)(σ_x²+σ_y²+c₂)]
```

- 밝기·대비·구조의 유사도를 곱으로 결합한다

**FID의 한계**

- 샘플 수에 민감하다. 보통 1만 장 이상 필요하고, 적으면 값이 편향된다
- Inception 특징에 의존하므로 그 모델이 학습한 도메인(ImageNet)과 다른 데이터에서는 신뢰도가 떨어진다. **의료 영상이나 의류 이미지에서 특히 주의해야 한다**
- 분포 거리이므로 개별 이미지의 품질은 알 수 없다
- 다양성 붕괴를 완전히 잡아내지 못한다

**면접 포인트**

**"FID가 좋으면 좋은 모델인가"** 라는 질문에 한계를 짚을 수 있어야 한다. 특히 T08(치과 영상)처럼 ImageNet과 전혀 다른 도메인에서는 FID를 그대로 믿기 어렵다. 그래서 **최종 목적 기준으로 평가하는 것**이 더 중요하다. 생성 데이터를 넣어 분할 성능이 올랐는지가 진짜 지표다. 이를 **다운스트림 평가**라고 하며, 생성 데이터 활용 연구의 표준적 접근이다.

### 합성 데이터로 학습하기

**직관**

레이블 붙은 데이터가 부족할 때, 생성모델로 데이터를 만들어 채운다. 특히 의료 영상은 개인정보 문제로 수집이 어렵고 전문의가 라벨링해야 해서 비용이 크다.

핵심 장점은 **레이블이 공짜로 딸려 온다**는 것이다. 세그멘테이션 마스크를 조건으로 이미지를 생성하면, 그 마스크가 곧 정답 레이블이다. 사람이 칠할 필요가 없다.

**주요 쟁점**

| 쟁점 | 내용 |
|------|------|
| 분포 이동 | 생성 데이터가 실제 분포와 다르면 학습된 모델이 실제 데이터에서 안 됨 |
| 다양성 부족 | 생성모델이 학습 데이터의 모드만 재현하면 새 정보가 없음 |
| 오류 증폭 | 생성모델의 편향이 다운스트림 모델에 전달됨 |
| 모델 붕괴 | 생성 데이터로 학습한 모델이 다시 데이터를 만드는 재귀가 반복되면 품질 저하 |
| 검증 오염 | 생성 데이터가 검증셋에 섞이면 성능이 부풀려짐 |

**바른 실험 설계**

```
1. 검증셋과 테스트셋은 반드시 실제 데이터로만 구성한다
2. 생성 데이터는 학습셋에만 넣는다
3. 실제 데이터만 쓴 기준선과 비교한다
4. 생성 데이터 비율을 바꿔 가며 성능 곡선을 본다
5. 생성모델 학습에 쓴 데이터가 테스트셋에 새어 들어가지 않았는지 확인한다
```

**면접 포인트**

**"가짜 데이터로 학습하면 가짜를 배우는 것 아닌가"** 라는 반문에 답할 준비가 필요하다. 답의 요지는 이렇다. 생성 데이터는 새로운 정보를 만들어 내지 못하지만, **기존 정보를 다양한 형태로 재배열해 모델이 불변성을 배우게 한다.** 데이터 증강의 정교한 형태로 보는 것이 정확하다. 그래서 실제 데이터를 완전히 대체할 수는 없고, 보완으로 써야 한다.

그리고 **평가는 반드시 실제 데이터로** 해야 한다는 점을 강조한다. 이것이 T08 논문의 실험 설계에서 확인해야 할 핵심이다.

## 예상 질문

#### Q001. GAN의 원리를 설명해 주세요. 🟢

**의도:** 가장 기본적인 확인 질문이다.

**답변:** 생성기와 판별기 두 신경망이 서로 반대되는 목표로 경쟁하며 학습합니다. 생성기는 무작위 잡음을 받아 가짜 데이터를 만들고, 판별기는 입력이 진짜인지 가짜인지 판정합니다. 생성기는 판별기를 속이려 하고 판별기는 속지 않으려 하는데, 이 경쟁이 균형에 도달하면 생성기가 진짜와 구별되지 않는 데이터를 만들게 됩니다. 목적함수는 판별기가 최대화하고 생성기가 최소화하는 미니맥스 형태입니다. 다만 실제 구현에서는 학습 초기에 생성기의 기울기가 사라지는 문제가 있어서, 생성기가 판별기 출력의 로그를 최대화하도록 손실을 바꿔 씁니다.

**꼬리질문:** 그 균형이라는 게 실제로 잘 잡힙니까?

#### Q002. 모드 붕괴가 무엇이고 어떻게 대응합니까? 🟡

**의도:** GAN을 실제로 학습시켜 봤는지 확인한다.

**답변:** 생성기가 다양한 결과 대신 몇 가지 패턴만 반복해서 만드는 현상입니다. 판별기를 속이는 이미지 하나를 찾으면 그것만 계속 만드는 게 생성기 입장에서 손해가 없기 때문에 생깁니다. 대응으로는 판별기가 배치 안의 다양성을 볼 수 있게 하는 미니배치 판별, 목적함수 자체를 Wasserstein 거리로 바꾸는 WGAN, 판별기에 스펙트럼 정규화를 걸어 너무 강해지지 않게 하는 방법이 있습니다. 실무에서는 먼저 생성 이미지를 눈으로 확인해 다양성이 있는지 보고, 두 손실의 추이를 비교해 어느 쪽이 압도하는지 확인했습니다.

**꼬리질문:** 손실값만 봐서는 모드 붕괴를 알 수 없다는 뜻입니까?

#### Q003. 확산모델의 학습이 GAN보다 안정적인 이유가 무엇입니까? 🟢

**의도:** 두 방법의 근본적 차이를 이해하는지 본다. 교신저자 논문이 확산모델이므로 반드시 나온다.

**답변:** 목표가 명확한 지도학습이기 때문입니다. GAN은 두 신경망이 경쟁하는 구조라 절대적인 정답이 없고, 판별기와 생성기의 실력 균형을 맞춰야 합니다. 확산모델은 이미지에 어떤 노이즈를 더했는지 알고 있는 상태에서 그 노이즈를 맞히는 회귀 문제입니다. 정답이 있는 문제라 손실이 떨어지면 실제로 나아진 것이고, 균형을 신경 쓸 필요가 없습니다. 대신 생성할 때 수십에서 수백 단계를 순차적으로 밟아야 해서 느리다는 대가가 있습니다.

**꼬리질문:** 학습할 때도 그 수백 단계를 다 거칩니까?

#### Q004. DDPM의 순방향 과정과 역방향 과정을 설명해 주세요. 🟡

**의도:** 확산모델을 수식 수준에서 이해하는지 본다.

**답변:** 순방향은 이미지에 가우시안 노이즈를 조금씩 더해 결국 완전한 잡음으로 만드는 과정입니다. 학습이 필요 없고 정해진 스케줄대로 더하기만 하면 됩니다. 중요한 점은 여러 단계를 거치지 않고 원본에서 임의 시점의 노이즈 이미지를 한 번에 만들 수 있다는 것입니다. 원본에 누적 알파의 제곱근을 곱하고, 1에서 누적 알파를 뺀 값의 제곱근에 표준정규 노이즈를 곱해 더하면 됩니다. 역방향은 신경망이 그 이미지에 섞인 노이즈를 예측하고 걷어 내는 과정입니다. 손실은 실제로 더한 노이즈와 예측한 노이즈의 MSE입니다.

**꼬리질문:** 신경망에 시간 단계 t를 왜 함께 입력합니까?

#### Q005. 확산모델이 느린데 어떻게 실용화됐습니까? 🟡

**의도:** 이론과 실용화의 간극을 아는지 본다.

**답변:** 두 방향으로 해결됐습니다. 하나는 잠재 확산모델입니다. 512×512 픽셀 공간에서 확산 과정을 돌리는 대신, 오토인코더로 64×64 정도의 잠재 표현으로 압축하고 그 공간에서 확산을 수행합니다. 계산량이 수십 배 줄어드는데, 인지적으로 중요하지 않은 세부는 오토인코더가 담당하기 때문에 품질 손실이 크지 않습니다. 다른 하나는 샘플링 단계 축소입니다. DDIM은 결정론적 샘플링으로 1000단계를 20에서 50단계로 줄였고, 증류 기법은 더 줄였습니다. 최근에는 flow matching 기반 모델이 더 적은 단계에서 동작합니다.

**꼬리질문:** 잠재 공간으로 압축하면 정보가 손실되는데 문제되지 않습니까?

#### Q006. 논문 하나는 GAN을 쓰고 하나는 확산모델을 쓰셨는데 왜 다릅니까? 🔴

**의도:** 방법 선택이 유행 추종인지 과제 요구에 따른 것인지 가른다. 두 논문을 나란히 놓는 질문이라 반드시 대비해야 한다.

**답변:** 과제의 요구가 달랐습니다. 치과 영상 논문은 인스턴스 분할 학습용 데이터를 늘리는 것이 목적이었습니다. 필요한 것은 마스크와 짝지어진 이미지를 대량으로 빠르게 만드는 것이었고, 도메인이 좁아서 다양성보다 실제 영상과의 유사성이 중요했습니다. GAN은 한 번의 순전파로 생성하므로 대량 생성에 유리합니다. 전후면 의류 논문은 텍스트 설명으로부터 서로 일관된 두 장의 이미지를 만드는 것이 목적이었습니다. 텍스트 조건을 세밀하게 반영해야 하고 생성 품질과 다양성이 중요했는데, 이 지점에서 확산모델이 확실히 낫습니다. 연도 차이도 있어서 활용 가능한 도구가 달랐던 것도 사실입니다.

**꼬리질문:** 지금 치과 영상 과제를 다시 한다면 확산모델을 쓰시겠습니까?

#### Q007. 생성한 가짜 데이터로 학습하면 가짜를 배우는 것 아닙니까? 🔴

**의도:** T08 논문의 근본 전제를 흔드는 질문이다. 방어 논리가 필요하다.

**답변:** 타당한 지적이고, 그래서 실험 설계가 중요합니다. 생성 데이터는 원리적으로 새로운 정보를 만들어 내지 못합니다. 학습 데이터에 있던 정보를 다양한 형태로 재배열하는 것에 가깝습니다. 그래서 저는 데이터 증강의 정교한 형태로 봐야 한다고 생각합니다. 회전이나 밝기 변화 같은 단순 증강보다 더 그럴듯한 변형을 만들어 주는 것입니다. 다만 이게 실제로 도움이 되는지는 주장이 아니라 실험으로 보여야 합니다. 검증과 테스트는 반드시 실제 데이터로만 하고, 실제 데이터만 쓴 기준선과 비교해서 성능이 올랐는지를 확인해야 합니다. 생성 데이터를 검증셋에 섞으면 성능이 부풀려지므로 그 분리가 가장 중요합니다.

**꼬리질문:** 그 실험에서 생성 데이터를 얼마나 넣었을 때 가장 좋았습니까?

#### Q008. FID가 무엇을 재는 지표입니까? 한계는 없습니까? 🟡

**의도:** 평가지표를 관행으로 쓰는지 이해하고 쓰는지 본다.

**답변:** 생성 이미지들의 분포와 실제 이미지들의 분포가 얼마나 가까운지를 재는 지표입니다. Inception 네트워크로 두 집합의 특징을 뽑고, 각각 가우시안으로 가정해 평균과 공분산을 구한 뒤 두 분포 사이의 거리를 계산합니다. 낮을수록 좋습니다. 한계가 몇 가지 있는데, 우선 샘플 수에 민감해서 보통 만 장 이상이 필요하고 적으면 값이 편향됩니다. 그리고 Inception 특징에 의존하기 때문에 ImageNet과 성질이 다른 도메인, 예를 들어 의료 영상에서는 신뢰도가 떨어집니다. 분포 거리라서 개별 이미지의 품질도 알 수 없습니다. 그래서 최종 목적 기준 평가를 함께 봐야 한다고 생각합니다.

**꼬리질문:** 최종 목적 기준 평가라는 게 구체적으로 무엇입니까?

#### Q009. 치과 영상에서 FID를 쓰셨다면 그 값을 믿을 수 있습니까? 🔴

**의도:** 앞 질문의 후속. 자기 논문의 평가 방식을 비판적으로 볼 수 있는지 본다.

**답변:** 절대값을 그대로 해석하기는 어렵다고 봅니다. FID의 특징 추출기가 ImageNet으로 학습된 모델이라 자연 이미지에 맞춰져 있고, 치과 방사선 영상은 그와 성질이 매우 다릅니다. 다만 같은 도메인 안에서 여러 설정을 비교하는 상대적 지표로는 여전히 의미가 있습니다. 절대 수치로 "이 정도면 좋다"고 말하기보다, 조건 A와 조건 B 중 어느 쪽이 실제 분포에 가까운지를 비교하는 용도로 쓰는 것이 맞습니다. 결국 판단의 근거는 이 데이터를 넣었을 때 분할 성능이 올랐는가였고, 그것이 이 연구에서 더 직접적인 증거라고 생각합니다.

**꼬리질문:** 그럼 논문에서 FID를 왜 보고했습니까?

#### Q010. 전면 이미지에서 후면을 만드는 게 왜 어렵습니까? 🟡

**의도:** T02의 문제 정의를 이해하는지 본다.

**답변:** 필요한 정보가 원본에 없기 때문입니다. 인페인팅처럼 주변 맥락으로 빈 곳을 채우는 문제라면 단서가 이미지 안에 있는데, 후면은 아예 보이지 않는 쪽이라 추론해야 합니다. 옷이 대체로 어떤 구조를 갖는지에 대한 사전 지식에 의존하게 됩니다. 그리고 자유롭게 만들면 되는 것도 아닙니다. 같은 옷이어야 하므로 색상, 소재, 패턴, 실루엣 같은 속성이 전면과 일치해야 합니다. 생성의 자유도는 필요한데 속성 일관성은 지켜야 하는, 두 요구가 충돌하는 문제입니다.

**꼬리질문:** 그 일관성을 어떻게 보장하셨습니까?

#### Q011. LLM으로 텍스트를 먼저 만들고 그걸로 이미지를 생성하는 이유가 무엇입니까? 🟡

**의도:** T02의 2단계 구조의 설계 의도를 묻는다.

**답변:** 확산모델은 프롬프트가 구체적이고 속성이 명시적일수록 좋은 결과를 냅니다. 사용자가 입력하는 짧은 문장, 예를 들어 흰 셔츠 같은 표현만으로는 소재나 카라 형태, 단추 배치 같은 세부가 지정되지 않아 생성할 때마다 다른 옷이 나옵니다. 전면과 후면을 각각 생성할 때 이 문제가 특히 커집니다. 두 번의 생성에서 서로 다른 세부가 나오면 같은 옷으로 보이지 않습니다. LLM으로 짧은 입력을 속성이 명시된 상세 설명으로 확장하고, 전면과 후면 설명을 일관되게 만들면 이 문제가 완화됩니다. Chain-of-Thought와 instruction tuning을 쓴 것도 그 확장이 임의적이지 않고 규칙을 따르게 하기 위한 것으로 이해하고 있습니다.

**꼬리질문:** LLM이 만든 설명이 잘못되면 이미지도 잘못되는 것 아닙니까?

#### Q012. ControlNet이 무엇이고 왜 필요합니까? 🟡

**의도:** 조건부 제어 기법을 아는지 본다.

**답변:** 텍스트만으로는 공간적 조건, 예를 들어 이 윤곽선을 따라라 이 자세로 그려라 같은 지시를 할 수 없습니다. ControlNet은 사전학습된 확산모델의 인코더를 복제해 옆에 붙이고, 그 복제본으로 엣지 맵이나 자세, 깊이 맵 같은 조건을 처리해 원본에 더합니다. 원본 가중치는 얼려 두기 때문에 기존 성능이 망가지지 않습니다. 연결 부분이 가중치 0으로 초기화된 합성곱이라, 학습 시작 시점에는 원본과 완전히 동일하게 동작하다가 점진적으로 개입합니다. 이 제로 초기화가 사전학습된 표현을 보호하는 핵심 장치입니다.

**꼬리질문:** 그럼 전후면 일관성에 ControlNet을 쓸 수 있겠습니까?

#### Q013. LoRA가 무엇이고 전체 파인튜닝과 어떻게 다릅니까? 🟡

**의도:** 효율적 적응 기법을 아는지 본다.

**답변:** 원본 가중치는 그대로 두고 가중치 변화량만 두 개의 낮은 계수 행렬의 곱으로 근사해 학습하는 방법입니다. 예를 들어 1000 곱하기 1000 행렬이면 백만 개 파라미터인데, 계수를 8로 잡으면 1000 곱하기 8 행렬 두 개, 즉 만 육천 개만 학습하면 됩니다. 메모리와 시간이 크게 줄고, 원본을 건드리지 않으니 여러 도메인용 LoRA를 만들어 갈아 끼울 수도 있습니다. 데이터가 적을 때는 전체 파인튜닝보다 과적합 위험도 작습니다. 대신 표현할 수 있는 변화가 저계수로 제한되므로, 도메인 차이가 아주 크면 전체 파인튜닝이 필요할 수 있습니다.

**꼬리질문:** 계수 r은 어떻게 정하십니까?

#### Q014. 분류기 프리 가이던스의 스케일을 키우면 어떻게 됩니까? 🟡

**의도:** 실제로 확산모델을 돌려 봤는지 확인하는 실무 질문이다.

**답변:** 프롬프트를 더 강하게 따르게 됩니다. 조건이 있을 때와 없을 때의 예측 차이를 증폭하는 방식이라, 스케일이 크면 조건 쪽으로 밀어붙입니다. 다만 대가가 있어서 채도가 과하게 올라가고 부자연스러워지며 다양성이 줄어듭니다. 너무 작으면 프롬프트를 잘 안 따르고 결과가 흐릿해집니다. 보통 7에서 8 근처를 기본으로 두고 과제에 따라 조정합니다. 속성을 정확히 반영해야 하는 과제라면 조금 높이고, 자연스러움이 중요하면 낮춥니다.

**꼬리질문:** 스케일을 조정하는 대신 프롬프트를 개선하는 게 낫지 않습니까?

#### Q015. pix2pix에서 L1 손실과 적대적 손실을 함께 쓰는 이유가 무엇입니까? 🟡

**의도:** 손실 설계의 의도를 이해하는지 본다.

**답변:** 두 손실이 서로 다른 역할을 합니다. L1 손실만 쓰면 가능한 여러 출력의 평균에 해당하는 결과가 나와서 흐릿해집니다. 정답과의 거리를 줄이는 데는 평균이 안전하기 때문입니다. 적대적 손실만 쓰면 선명하지만 입력과 무관하게 그럴듯한 이미지를 만들 수 있습니다. 둘을 합치면 L1이 입력에 대한 충실도를, 적대적 손실이 선명함과 사실성을 담당해서 입력에 맞으면서도 선명한 결과가 나옵니다. 확산모델에서도 재구성 목표와 사실성 제약을 함께 두는 비슷한 발상이 쓰입니다.

**꼬리질문:** L1 대신 L2를 쓰면 어떻게 됩니까?

#### Q016. 생성모델 연구가 계속 바뀌는데 어떻게 따라가십니까? 🟡

**의도:** 학습 태도와 최신 동향 파악 능력을 본다.

**답변:** 구조 자체보다 어떤 문제를 풀려고 그 구조가 나왔는지를 봅니다. GAN에서 확산모델로 넘어간 것도 결국 학습 안정성과 다양성이라는 문제 때문이었고, 잠재 확산모델은 연산량, ControlNet은 제어 가능성 문제였습니다. 이렇게 문제 중심으로 정리해 두면 새 모델이 나와도 어느 자리에 놓이는지 파악이 됩니다. 구체적으로는 관심 주제의 최신 논문을 훑고, 라이브러리 문서와 구현체를 직접 돌려 보는 편입니다. 논문만 읽으면 실제로 무엇이 어려운지 감이 안 잡히는 경우가 많았습니다.

**꼬리질문:** 최근에 본 것 중에 인상 깊었던 연구가 있습니까?
