# T07 — 준지도 시맨틱 분할의 배경 구분을 위한 멀티뷰 통합 앙상블

> **A Multi-View Integrated Ensemble for the Background Discrimination of Semi-Supervised Semantic Segmentation**
> Applied Sciences, 2023, 13(24), 13255 · 공저(4/6)

---

## 0. 30초 요약

> 준지도 시맨틱 분할에서는 레이블 없는 이미지에 모델이 스스로 만든 의사 레이블을 붙여 학습합니다. 문제는 그 의사 레이블이 틀릴 때인데, 저희가 확인한 것은 **틀린 전경 레이블의 대부분이 서로 다른 전경 클래스끼리 헷갈린 게 아니라 배경과 전경을 헷갈린 결과**라는 것이었습니다. 개를 고양이로 잘못 본 게 아니라 배경을 개로 본 것입니다. 그렇다면 배경과 전경만 잘 가르는 별도의 모델을 만들면 의사 레이블 품질을 크게 올릴 수 있습니다. 그래서 **출력 섭동**이라는 새 방식으로 교사 모델을 여러 개 만들었습니다. 클래스가 6개면 교사 5명을 두고, n번째 교사는 "배경 / n번 클래스 / 나머지 전부" 3개로만 판단하게 합니다. 교사마다 세상을 보는 관점이 다른 셈입니다. 이 교사들의 예측을 통합해 학생 모델을 학습시켰더니, PASCAL VOC에서 기존 최고 성능 대비 배경·전경 분류 mIoU가 1/8 설정에서 1.84%p 올랐고, 기존 SOTA 모델들에 이 결과를 붙여 주자 전부 성능이 개선됐습니다.

## 2. 왜 이 연구를 했나

### 분할 과제의 근본 비용

시맨틱 분할은 이미지의 **픽셀 하나하나에 클래스를 부여**하는 과제다. 로보틱스, AR/VR, 자율주행, 질병 진단 등에 널리 쓰인다.

문제는 데이터다.

| 과제 | 필요한 레이블 |
|------|---------------|
| 이미지 분류 | 이미지당 **레이블 1개** |
| 시맨틱 분할 | **픽셀 단위 레이블** |

논문의 표현: 픽셀 단위 라벨링은 **높은 비용**을 초래한다. 그래서 소량의 레이블 데이터와 대량의 비레이블 데이터를 효과적으로 활용하는 준지도 시맨틱 분할 연구가 진행돼 왔다.

### 이 논문이 발견한 것 — 연구의 출발점

**논문의 핵심 관찰**

> 레이블 없는 이미지 학습을 위한 의사 레이블에서, **잘못된 전경 클래스 의사 레이블의 대부분이 배경 클래스 혼동에 의해 발생하며, 서로 다른 전경 클래스 간의 혼동이 아니라는 것**을 확인했다.

**이 관찰이 왜 중요한가**

기존 연구들은 의사 레이블의 신뢰도를 높이기 위해 여러 방법을 썼다. 일관성 기반 학습, 신뢰할 만한 의사 레이블 필터링 등이다. 하지만 **어떤 종류의 오류가 지배적인지는 따로 분석하지 않았다.**

오류가 전경끼리의 혼동이라면(개 vs 고양이) 클래스 간 구분 능력을 높여야 한다. 그런데 **배경과 전경의 혼동**이라면, 그 이진 구분만 잘해도 문제의 대부분이 해결된다.

논문 결론부의 표현:

> 이는 준지도 시맨틱 분할에서 **이 혼동 문제만 완화하면 고성능 모델을 구현할 수 있다**는 뜻이다.

### 왜 배경 구분이 어려운가

논문이 명시적으로 논하지는 않지만, 배경이 어려운 이유는 두 가지다.

1. **배경은 일관된 외형이 없다.** 개나 자동차는 공통된 형태가 있어 학습되는데, 배경은 하늘일 수도 벽일 수도 아무것도 아닐 수도 있다. 하나의 클래스로 묶기 어렵다
2. **픽셀 수가 압도적으로 많다.** 심한 클래스 불균형이 생긴다

→ 상세: [03_비전_검출·분할·키포인트.md](../01_foundations/03_비전_검출·분할·키포인트.md)의 `### 시맨틱 분할`

### 이 논문의 해법

**전경·배경 판별 전용 모델**을 만들되, 그 모델을 **멀티뷰 통합 앙상블(MVIE)** 이라는 새 방식으로 학습시킨다. 핵심은 **출력 섭동(output perturbation)** 이라는 새로운 섭동 방식이다.

## 3. 사전지식 (A to Z)

### 3.1 준지도 학습과 섭동

준지도 학습의 핵심 아이디어 중 하나는 **일관성 정규화(consistency regularization)** 다. 같은 입력에 약간의 변형을 주어도 모델의 출력이 같아야 한다는 제약을 건다.

**섭동의 종류**

| 종류 | 방법 | 예 |
|------|------|-----|
| **입력 섭동(input perturbation)** | 입력 이미지에 증강을 가한다 | 색 변환, CutMix, 강한 증강 |
| **특징 섭동(feature perturbation)** | 중간 특징에 노이즈를 더한다 | 드롭아웃, VAT |
| **네트워크 섭동(network perturbation)** | 서로 다른 초기값의 모델을 쓴다 | Cross Pseudo Supervision |
| **출력 섭동(output perturbation)** | **출력 공간의 정의 자체를 바꾼다** | **이 논문의 MVIE** |

**출력 섭동이 이 논문의 신규성이다.** 입력이나 특징이 아니라, **각 모델이 풀어야 할 문제 자체를 다르게 정의**한다.

### 3.2 교사-학생 구조

준지도 학습의 표준 구조다. 교사(teacher)가 레이블 없는 데이터에 대해 예측을 만들고, 그 예측을 의사 레이블 삼아 학생(student)을 학습시킨다.

**이 논문의 특이한 점**: 교사가 **여러 명**이고, 각 교사가 **서로 다른 문제**를 푼다.

### 3.3 확증 편향

의사 레이블의 근본 위험이다. 모델이 틀린 예측을 자신 있게 하면, 그 틀린 답이 레이블이 되어 다시 학습되고 오류가 강화된다.

**앙상블이 이를 완화하는 원리**: 여러 모델이 서로 다른 방식으로 틀리면, 다수결에서 개별 오류가 상쇄된다. 단 **모델들이 서로 달라야** 한다. 같은 방식으로 틀리면 앙상블해도 소용없다.

### 3.6 분할 지표 — mIoU와 IoU

이 논문은 mIoU에 더해 **픽셀 수준 성능을 보기 위해 정확도와 F1 점수도** 보고한다.

**BG IoU / FG IoU를 따로 보는 것**이 이 논문의 특징이다. 이진 분류로 바꿔 평가하기 때문이다.

## 4. 방법론 단계별 해부

### 4.1 문제 정의 (논문 3.1절)

```
레이블 데이터:   D_L = {(x_i^l, y_i^l)}_{i=1}^{|D_L|}     ← 소량
비레이블 데이터: D_U = {x_i^u}_{i=1}^{|D_U|}              ← 대량

x_i^l, x_i^u ∈ R^{H×W×3}      (H: 높이, W: 너비)
y_i^l ∈ R^{H×W×C}             (C: 클래스 수)
```

**핵심 설계: 레이블을 교사용과 학생용으로 각각 재정의한다.**

### 4.2 레이블 변환 — 이 논문의 핵심 발상

**교사용 레이블 (식 1)**

```
              ⎧ 0,  if y_i^l = 0        (배경)
y_i^l(n)  =   ⎨ 1,  if y_i^l = n        (n번째 클래스)
              ⎩ 2,  otherwise           (그 외 모든 전경)
```

**학생용 레이블 (식 2)**

```
              ⎧ 0,  if y_i^l = 0        (배경)
y_i^l(s)  =   ⎨
              ⎩ 1,  otherwise           (전경 전부)
```

**구체적 예시 (클래스 6개인 경우)**

교사는 `C − 1 = 5`명이 만들어진다. 각 교사의 세 클래스가 무엇을 의미하는지는 **교사마다 다르다.**

| 교사 | 클래스 0 | 클래스 1 | 클래스 2 |
|------|----------|----------|----------|
| 교사 1 | 배경(0) | **의미 클래스 1** | 2, 3, 4, 5 |
| 교사 2 | 배경(0) | **의미 클래스 2** | 1, 3, 4, 5 |
| 교사 3 | 배경(0) | **의미 클래스 3** | 1, 2, 4, 5 |
| 교사 4 | 배경(0) | **의미 클래스 4** | 1, 2, 3, 5 |
| 교사 5 | 배경(0) | **의미 클래스 5** | 1, 2, 3, 4 |
| **학생** | **배경(0)** | **전경 전부(1~5)** | — |

**이것이 "멀티뷰(multi-view)"의 의미다.** 각 교사가 같은 이미지를 보되 **서로 다른 관점으로 세상을 나눈다.** 교사 1에게는 클래스 1이 특별하고 나머지는 뭉뚱그려진 "기타"인데, 교사 2에게는 클래스 2가 특별하다.

**왜 이 구조가 효과적인가**

이것이 논문의 핵심 논리이므로 정확히 이해해야 한다.

1. **각 교사는 3-클래스 문제만 푼다.** 20-클래스 문제보다 훨씬 쉽다
2. **각 교사가 서로 다른 방식으로 틀린다.** 교사 1은 클래스 1 주변에서 정밀하고 나머지는 뭉뚱그리며, 교사 2는 그 반대다. 앙상블의 전제인 **다양성**이 구조적으로 보장된다
3. **모든 교사가 배경(클래스 0)은 공통으로 판단한다.** 배경 판정에 대해서는 5명의 독립적 의견이 모이는 셈이다

**3번이 결정적이다.** 이 논문의 목표가 배경 구분이므로, 배경에 대해서만 여러 관점의 합의를 얻는 구조를 만든 것이다.

### 4.3 네트워크 구조 (논문 Figure 3)

```
                레이블 데이터 (D_L)
                       ↓
        ┌──────────────┴──────────────┐
        ↓                             ↓
   교사 1 ~ 교사 C−1                 학생
   (인코더 h + 디코더 g)           (디코더만)
        ↓                             ↑
   지도 손실 (CE)              고정 교사가 인코딩한 특징
        
                비레이블 데이터 (D_U)
                       ↓
        ┌──────────────┴──────────────┐
        ↓ 약한 증강                    ↓ 강한 증강
   모든 교사가 예측                 고정 교사가 인코딩
        ↓                             ↓
   MVIE 앙상블로                    학생이 디코딩해 예측
   각 교사의 의사 레이블 생성            ↓
        ↓                        모든 교사 예측의
   교사 비지도 손실              하드 보팅 앙상블 = 학생 의사 레이블
                                      ↓
                                 학생 비지도 손실
```

**구성 요소 정리**

| 요소 | 구조 | 출력 |
|------|------|------|
| **교사** `f_θt = {f_θt(i)}_{i=1}^{C−1}` | 인코더 `h_θh^t` + 디코더 `g_θg^t` + 분할 헤드 | `ŷ^t ∈ {0,1,2}^{H×W}` |
| **학생** | **디코더만** `g_θg^s` | `ŷ^s ∈ {0,1}^{H×W}` |
| **고정 교사(fixed teacher)** | 교사 중 하나 | 입력을 인코딩해 **학생에게 특징을 전달** |

**학생이 디코더만 갖는 것**이 특이하다. 인코딩은 고정 교사가 담당한다. 학생은 이미 잘 학습된 특징 공간에서 이진 분할만 배우면 된다.

**모든 교사와 학생은 서로 다른 초기 가중치**를 갖는다. 앙상블 다양성을 위한 장치다.

### 4.4 손실함수 (논문 식 3)

```
L_T = L_sup^t + λ_t · L_unsup^t      (교사)
L_S = L_sup^s + λ_s · L_unsup^s      (학생)
```

| 항 | 계산 방식 |
|----|-----------|
| `L_sup^t` | 식 (1)로 변환된 교사 레이블에 대한 **표준 교차엔트로피** |
| `L_unsup^t` | **MVIE로 생성한 각 교사의 의사 레이블**에 대한 표준 교차엔트로피 |
| `L_sup^s` | 식 (2)로 변환된 학생 레이블에 대한 표준 교차엔트로피 |
| `L_unsup^s` | **모든 교사의 하드 보팅 앙상블**로 생성한 학생 의사 레이블에 대한 표준 교차엔트로피 |

**손실함수 자체는 전부 표준 교차엔트로피다.** 신규성은 손실 형태가 아니라 **레이블을 어떻게 만드느냐**에 있다.

### 4.5 두 종류의 앙상블 — 구분해야 한다

| 대상 | 앙상블 방식 | 입력 |
|------|-------------|------|
| **교사의 의사 레이블** | **MVIE** (멀티뷰 통합 앙상블) | **다른 모든 교사**의 예측 |
| **학생의 의사 레이블** | **하드 보팅** | **모든 교사**의 예측 |

**교사끼리 서로를 가르친다**는 점이 중요하다. n번째 교사의 의사 레이블은 자기 자신이 아니라 **다른 교사들**의 예측으로 만들어진다. 자기 예측을 자기가 학습하면 확증 편향이 그대로 강화되기 때문이다.

### 4.6 증강 전략 — 교사와 학생이 다르다

| 대상 | 증강 | 섭동 유형 |
|------|------|-----------|
| **교사** | **약한 증강(weak augmentation)** | **출력 섭동** (레이블 정의를 다르게) |
| **학생** | **강한 증강(strong augmentation)** | **입력 섭동** |

**논문의 명시적 서술**: "학생은 입력 섭동에 기반해 학습되고, 교사들은 새로운 출력 섭동에 기반해 학습된다."

**왜 이렇게 나누는가**: 교사는 신뢰할 만한 의사 레이블을 만들어야 하므로 입력을 크게 흔들면 안 된다. 학생은 강한 증강으로 일반화 능력을 키운다. FixMatch 계열의 표준 전략이며, 여기에 **교사 쪽 다양성을 출력 섭동으로 추가**한 것이 신규성이다.

## 5. 핵심 수식

**식 (1) — 교사용 레이블 변환**

```
             ⎧ 0,  if y_i^l = 0
y_i^l(n) =   ⎨ 1,  if y_i^l = n
             ⎩ 2,  otherwise
```

- `n`: 교사 번호 (1 ~ C−1)
- 각 교사가 **자기 번호에 해당하는 클래스만 특별 취급**하고 나머지 전경은 뭉뚱그린다

**식 (2) — 학생용 레이블 변환**

```
             ⎧ 0,  if y_i^l = 0
y_i^l(s) =   ⎨
             ⎩ 1,  otherwise
```

배경 대 전경의 **이진 문제**로 축소한다.

**식 (3) — 전체 손실**

```
L_T = L_sup^t + λ_t · L_unsup^t
L_S = L_sup^s + λ_s · L_unsup^s
```

- `λ_t`, `λ_s`: 교사·학생의 비지도 손실 가중치

**식 (4), (7)** — 레이블 데이터에 대한 표준 교차엔트로피 (학생·교사 각각)
**식 (6)** — MVIE 기반 교사 비지도 손실
**식 (9)** — 하드 보팅 기반 학생 비지도 손실

### 7.2 이 표에서 반드시 읽어야 할 것

**① 레이블이 적을수록 효과가 크다 — 가장 중요한 관찰**

```
1/8 (레이블 최소):  +1.84%p   ← 큰 개선
1/4:                +0.36%p   ← 작은 개선
1/2 (레이블 최다):  +0.003%p  ← 사실상 차이 없음
```

**이것은 준지도 학습 방법으로서 올바른 방향이다.** 레이블이 많으면 지도학습만으로도 충분하므로 준지도 기법의 여지가 줄어든다. 레이블이 극도로 적을 때 도움이 되는 것이 이 분야 방법의 가치다.

**논문의 해석**: "1/8이라는 작은 레이블 비율 실험에서 BG IoU가 오르면서 FG IoU가 동시에 크게 올랐다. 이는 **실제 정보가 적은 환경에서 더 정확한 전경 의사 레이블을 사용한 결과**로 해석할 수 있다."

**② FG IoU의 개선이 BG IoU보다 크다**

1/8에서:
```
BG IoU: 88.943 → 89.924  (+0.98)
FG IoU: 76.452 → 79.160  (+2.71)   ← 2.8배 큰 개선
```

**논문 제목은 "배경 구분"인데 실제로 크게 개선된 것은 전경 IoU다.** 모순처럼 보이지만 그렇지 않다. 배경을 잘 가려내면 그만큼 전경 영역이 정확해진다. **배경 오류가 전경 IoU를 갉아먹고 있었다**는 논문의 관찰과 정확히 일치하는 결과다.

**③ 1/2 분할에서 +0.003%p는 사실상 동률이다**

PS-MT의 85.108 대 Ours의 85.111. 소수점 셋째 자리 차이다. 게다가 Acc(0.931 vs 0.930)와 BG IoU(90.465 vs 90.273)는 **PS-MT가 더 높다.**

**정직하게 말해야 하는 지점이다.** 논문도 "+0.003%"라고 그대로 적었지 부풀리지 않았다.

**추론 시간이 같다는 점이 중요하다.** 학생 모델 하나만 배포하면 되기 때문이다. 여러 교사는 학습에만 쓰인다.

### 8.1 교사 수가 클래스 수에 비례한다 — 가장 큰 구조적 약점

**교사 = C − 1명**이다. PASCAL VOC는 21개 클래스이므로 **교사가 20명**이다.

| 데이터셋 | 클래스 | 교사 수 |
|----------|--------|---------|
| PASCAL VOC 2012 | 21 | **20** |
| Cityscapes | 19 | 18 |
| ADE20K | 150 | **149** |
| COCO-Stuff | 171 | **170** |

**ADE20K에 적용하면 교사가 149명이다.** 각 교사가 DeepLabV3+ 전체를 갖는다면 학습 비용이 감당 불가능해진다.

**논문이 이 확장성 문제를 정면으로 다루지 않았다.** 실험도 PASCAL VOC 하나뿐이다.

**답변 전략**: 인정하고 완화 방향을 제시한다. "클래스 수에 선형으로 비례하는 구조라 클래스가 많은 데이터셋에는 그대로 적용하기 어렵습니다. 클래스를 그룹으로 묶어 교사 수를 줄이거나, 백본을 공유하고 헤드만 분리하는 방식으로 완화할 수 있다고 봅니다. 다만 그렇게 하면 교사 간 다양성이 줄어드는 트레이드오프가 생깁니다."

### 8.2 데이터셋이 하나뿐이다

PASCAL VOC 2012에서만 실험했다. 배경 클래스가 필요하다는 이유로 Cityscapes를 배제한 것은 타당하지만, **배경 클래스가 있는 다른 데이터셋**(ADE20K, COCO)에서 검증하지 않았다.

### 8.3 1/2 분할에서 개선이 사실상 없다

+0.003%p는 의미 있는 차이가 아니다. 게다가 Acc와 BG IoU는 PS-MT가 더 높다.

### 8.4 제거 실험이 없다

MVIE의 효과를 분리해 보이는 실험이 없다. 확인해야 할 것들:

- 단순히 교사를 여러 개 두는 것(네트워크 섭동)만으로도 같은 효과가 나는가?
- **출력 섭동**이라는 레이블 재정의가 정말 기여하는가?
- 교사 수를 줄이면 성능이 얼마나 떨어지는가?
- 하드 보팅 대신 소프트 보팅을 쓰면?

**MVIE가 신규성인데 MVIE 없이 돌린 결과가 없다.** 따라서 개선이 출력 섭동 때문인지, 단순히 앙상블 때문인지 구분할 수 없다.

**답변 전략**: 방어하지 말고 인정한다. "MVIE의 기여를 분리하는 제거 실험이 없는 것이 이 논문의 가장 큰 약점입니다. 같은 수의 교사를 두되 출력 섭동 없이 전부 같은 다중 클래스 문제를 풀게 한 대조군이 있었어야 개선의 원인을 특정할 수 있습니다."

**이 지적을 스스로 하면 논문을 비판적으로 읽었다는 것이 드러난다.**

### 8.5 하이퍼파라미터가 보고되지 않았다

식 (3)의 `λ_t`, `λ_s`가 비지도 손실의 가중치인데 **값이 논문에 없다.** 준지도 학습에서 이 가중치는 성능에 큰 영향을 주는 핵심 파라미터다. 재현성 관점에서 결함이다.

### 8.6 배경 오류가 지배적이라는 관찰의 근거가 약하다

논문의 출발점인 **"틀린 전경 의사 레이블의 대부분이 배경 혼동 때문"** 이라는 관찰이 정량적으로 뒷받침되지 않았다.

혼동 행렬이나 오류 유형별 비율 같은 분석 표가 있어야 하는데, 서술만 있다.

**답변 전략**: "이 관찰이 연구 전체의 전제인데, 혼동 행렬로 오류 유형별 비율을 정량화해 제시했어야 합니다. 배경 혼동이 몇 퍼센트이고 전경 간 혼동이 몇 퍼센트인지 수치가 있었다면 문제 설정이 훨씬 설득력 있었을 것입니다."

### 8.7 학생이 디코더만 갖는 구조의 제약

학생은 **고정 교사가 인코딩한 특징**을 받아 디코딩만 한다. 즉 학생의 표현 학습 능력이 고정 교사에 묶여 있다.

고정 교사가 잘못 학습되면 학생도 그 한계를 넘을 수 없다. **어느 교사를 고정 교사로 삼는지가 성능에 영향을 줄 텐데, 그 선택 기준이 논문에 없다.**

### 8.8 학습 비용

논문이 인정한 대로 학습 시간이 길다. 다만 **구체적 수치가 없다.** "더 길다"고만 서술한다.

RTX 3090 두 장으로 교사 20명 + 학생 1명을 80에폭 학습하는 비용이 실제로 얼마인지 알 수 없어, 실용성 판단이 불가능하다.

**대응 논리**: 추론 시간은 동일하다는 점이 실용적 완화 요소다. 학습은 한 번이고 추론은 반복되므로, 배포 관점에서는 부담이 없다.

#### Q008. 학생 모델이 디코더만 갖는 이유가 무엇입니까? 🟡

**의도:** 구조 설계의 의도를 이해하는지 본다.

**답변:** 인코딩은 고정 교사가 담당하기 때문입니다. 교사들은 이미 레이블 데이터로 학습되어 좋은 특징 공간을 갖고 있고, 학생이 할 일은 그 특징 공간에서 배경과 전경을 가르는 이진 분할입니다. 표현 학습을 처음부터 다시 할 필요가 없다는 판단입니다. 파라미터가 줄고 학습이 빨라지는 이점도 있습니다. 다만 이 구조에는 제약이 따르는데, 학생의 성능이 고정 교사의 표현력에 묶입니다. 고정 교사가 놓친 정보는 학생이 복원할 수 없습니다. 그리고 어느 교사를 고정 교사로 삼을지가 성능에 영향을 줄 텐데, 논문에 그 선택 기준이 명시돼 있지 않은 것은 아쉬운 부분입니다.

**꼬리질문:** 고정 교사를 바꿔 가며 학습하면 안 됩니까?

#### Q009. 교사의 의사 레이블은 어떻게 만듭니까? 자기 예측을 쓰면 안 됩니까? 🟡

**의도:** 확증 편향 문제를 이해하는지 본다.

**답변:** 각 교사의 의사 레이블은 자기 자신이 아니라 다른 모든 교사의 예측으로 만듭니다. 자기 예측을 자기가 학습하면 확증 편향이 그대로 강화되기 때문입니다. 모델이 틀린 예측을 자신 있게 하면 그 틀린 답이 레이블이 되고, 다시 학습되면서 오류가 굳어집니다. 다른 교사들의 예측을 통합해서 쓰면, 각 교사가 서로 다른 관점으로 문제를 보기 때문에 한 교사의 확신에 찬 오류가 다른 교사들에게서 걸러질 가능성이 생깁니다. 학생 쪽은 방식이 조금 다른데, 모든 교사 예측의 하드 보팅 앙상블을 의사 레이블로 씁니다. 교사끼리는 MVIE로 통합하고 학생에게는 하드 보팅으로 준다는 것이 구분해야 할 지점입니다.

**꼬리질문:** 하드 보팅 대신 소프트 보팅을 쓰면 어떻게 됩니까?

#### Q010. 교사에는 약한 증강, 학생에는 강한 증강을 쓴 이유가 무엇입니까? 🟡

**의도:** 준지도 학습의 표준 전략을 아는지 본다.

**답변:** 역할이 다르기 때문입니다. 교사는 신뢰할 만한 의사 레이블을 만들어야 하는데, 입력을 크게 흔들면 예측이 불안정해져서 레이블 품질이 떨어집니다. 그래서 약한 증강만 씁니다. 학생은 그 레이블을 정답 삼아 배우는 쪽인데, 강한 증강을 준 어려운 입력에서도 같은 답을 내도록 강제하면 일반화 능력이 올라갑니다. FixMatch 계열에서 확립된 표준 전략입니다. 이 논문의 추가 요소는 교사 쪽에 출력 섭동을 넣은 것인데, 입력은 약하게 두면서 각 교사가 푸는 문제를 다르게 만들어 다양성을 확보한 것입니다. 입력 안정성과 모델 다양성을 동시에 얻으려는 설계로 읽었습니다.

**꼬리질문:** 그럼 교사에도 강한 증강을 주면 어떻게 됩니까?

#### Q011. Cityscapes를 안 쓴 이유가 무엇입니까? 🟢

**의도:** 실험 설계의 근거를 아는지 확인한다. 쉬운 질문이지만 못 답하면 곤란하다.

**답변:** 배경 클래스가 없기 때문입니다. Cityscapes는 도로, 건물, 차량처럼 모든 클래스가 객체 클래스로 구성돼 있고 별도의 배경 클래스가 없습니다. 저희 연구 목적이 배경과 전경을 잘 구분하는 것이라 배경 클래스가 없으면 문제 자체가 성립하지 않습니다. 그래서 20개 객체 클래스에 배경 클래스 하나를 갖는 PASCAL VOC 2012를 썼습니다. 데이터셋 선택이 연구 목적에서 도출된 경우라고 생각합니다. 다만 그 결과로 데이터셋이 하나뿐이 됐고, 배경 클래스가 있는 다른 데이터셋인 ADE20K나 COCO에서는 검증하지 못한 것이 한계입니다.

**꼬리질문:** 그럼 이 방법은 배경 클래스가 있는 데이터셋에서만 쓸 수 있습니까?

#### Q012. 여러 네트워크를 쓰면 학습 비용이 클 텐데 실용적입니까? 🟡

**의도:** 비용 대비 효과를 판단하는지 본다.

**답변:** 학습 비용은 분명히 큽니다. 논문에서도 여러 네트워크로 구성되어 학습 시간이 더 길다고 한계로 인정했습니다. 다만 중요한 완화 요소가 있는데, 추론 시간은 다른 방법과 비슷합니다. 배포할 때는 학생 모델 하나만 쓰면 되고 교사들은 학습에만 필요하기 때문입니다. 학습은 한 번이고 추론은 서비스 기간 내내 반복되므로, 실제 배포 관점에서는 부담이 크지 않다고 봅니다. 다만 논문에 학습 시간의 구체적 수치가 없어서 실용성을 판단하기 어려운 것은 사실입니다. RTX 3090 두 장으로 교사 20명과 학생을 80에폭 학습하는 데 얼마나 걸리는지 밝혔어야 한다고 생각합니다.

**꼬리질문:** 그 시간을 줄이려면 무엇을 하시겠습니까?

#### Q013. 기존 SOTA 모델에 붙였더니 전부 좋아졌다는데, 어느 모델에서 가장 효과가 컸습니까? 🟡

**의도:** 결과를 세밀하게 읽었는지 본다.

**답변:** U²PL에서 가장 컸습니다. 1/8 설정에서 73.004에서 74.945로 1.941 올랐고 1/4에서도 1.934 올랐습니다. 다른 두 모델보다 뚜렷하게 큽니다. 논문에서 이 차이를 해석하지는 않았는데, 제 생각에는 U²PL의 성격과 관련이 있어 보입니다. U²PL은 신뢰도가 낮은 의사 레이블도 버리지 않고 대조 학습으로 활용하는 방법입니다. 신뢰도가 낮은 예측이 많다는 것은 배경 혼동이 많다는 뜻일 수 있고, 그렇다면 배경 판별을 개선해 주는 저희 모델의 도움을 가장 많이 받았을 것입니다. 논문에 없는 해석이라 확정적으로 말씀드릴 수는 없고, 확인하려면 각 모델의 오류 유형을 분석해 봐야 합니다.

**꼬리질문:** 그 해석이 맞는지 어떻게 검증하시겠습니까?

#### Q014. 이 논문에서 본인 기여는 무엇입니까? 🔴

**의도:** 4/6 저자이므로 반드시 나온다.

**답변:** 논문의 저자 기여도 항목에 명시된 대로 원고 초안 작성과 검토·편집에 참여했습니다. 초안 작성은 제1저자인 곽현민 님과 둘이 담당했습니다. 방법론 설계와 소프트웨어 구현은 제1저자가 맡았습니다. 제가 맡은 부분은 `[ 직접 작성 — 원고 중 어느 부분을 썼는지 ]`입니다. 원고를 쓰려면 방법론과 실험 결과를 이해해야 해서, 그 과정에서 준지도 학습에서 의사 레이블의 품질이 왜 결정적인지, 앙상블 다양성을 어떻게 확보하는지를 정리하게 됐습니다. 앞서 말씀드린 제거 실험의 부재 같은 한계도 그때 인식한 부분입니다.

**꼬리질문:** 그럼 원고 작성 중에 방법론에 대해 제기하신 의견이 있었습니까?

#### Q015. 이 연구를 지금 다시 한다면 무엇을 바꾸시겠습니까? 🟡

**의도:** 비판적 사고와 개선 능력을 본다.

**답변:** 세 가지입니다. 첫째, 제거 실험을 반드시 넣겠습니다. 같은 수의 교사를 두되 출력 섭동 없이 전부 같은 문제를 풀게 한 대조군, 교사 수를 줄인 경우, 하드 보팅 대신 소프트 보팅을 쓴 경우를 비교해서 개선의 원인을 특정하겠습니다. 둘째, 연구의 전제인 배경 혼동이 지배적이라는 관찰을 혼동 행렬로 정량화해 제시하겠습니다. 셋째, 확장성 문제를 다루겠습니다. 백본을 공유하고 헤드만 분리하는 구조로 교사 수의 비용을 낮춘 뒤, 그때도 출력 섭동의 효과가 유지되는지 확인하겠습니다. 그래야 클래스가 많은 데이터셋으로 넘어갈 수 있습니다.

**꼬리질문:** 그중 가장 먼저 하시겠습니까?
