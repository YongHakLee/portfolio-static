# T08 — 인스턴스 분할을 위한 GAN 기반 치과 영상 데이터 생성

> **Dental Image Data Generation for Instance Segmentation using Generative Adversarial Networks**
> Quantitative Bio-Science, Vol. 42, No. 2, pp. 111–121 (2023) · 공저(6/7)

---

## 0. 30초 요약

> 의료 영상에 딥러닝을 적용하려 해도 임상 데이터가 절대적으로 부족합니다. 치과 분야는 특히 심한데, 개인정보 문제로 수집이 어렵고 전문의가 픽셀 단위로 라벨링해야 해서 비용이 큽니다. 이 연구는 GAN으로 치아 영상을 생성해 데이터를 늘리고, 그 데이터가 실제로 인스턴스 분할 성능을 올리는지 검증했습니다. 방법은 pix2pix 계열의 조건부 GAN인데, 먼저 원본 317장에 노이즈 함수를 적용해 상태가 나쁜 이미지를 만들어 **짝지어진 데이터셋**을 구성하고, 그것으로 GAN을 학습시켜 **나쁜 상태 → 좋은 상태** 변환을 배우게 했습니다. 최종적으로 원본 317장 + GAN 생성 120장 + 노이즈 생성 317장 = 754장을 확보했습니다. Mask R-CNN 성능을 비교했더니 시뮬레이션 데이터에서는 분할 AP가 0.388에서 0.750으로 거의 두 배가 됐습니다. 다만 **실제 치아 영상에서의 개선은 훨씬 작았다**는 점을 정확히 알고 있어야 합니다.

## 2. 왜 이 연구를 했나

### 의료 영상 딥러닝의 병목

논문 초록의 진단:

> 딥러닝은 낭종, 종양, 감염 조직 같은 질병 내 병원성 구조를 보여 주거나 세포핵, 간 종양 같은 객체를 인식해 의사를 도울 수 있다. 그러나 **진단용 딥러닝 기술의 발전은 임상 영상 데이터의 부족으로 저해되어 왔다. 치과 분야에서는 특히 그렇다.**

**왜 의료 영상 데이터가 부족한가** (일반적 배경)

| 요인 | 내용 |
|------|------|
| 개인정보 | 환자 동의와 IRB 승인이 필요하고 공개 배포가 제한된다 |
| 라벨링 비용 | **전문의**가 픽셀 단위로 칠해야 한다. 일반인이 할 수 없다 |
| 희귀 질환 | 드문 병변은 애초에 사례 수가 적다 |
| 기관 간 이질성 | 장비와 촬영 프로토콜이 달라 데이터를 합치기 어렵다 |

### 이 논문의 접근

**GAN으로 데이터를 만든다.** 그리고 그 데이터가 실제로 도움이 되는지를 **다운스트림 과제(인스턴스 분할)의 성능**으로 검증한다.

논문 초록:

> 우리는 GAN을 이용한 치과 영상 생성 방법을 제안한다. 이 논문에서 우리는 **GAN 생성 데이터를 포함한 데이터셋으로 학습한 Mask R-CNN**과 **포함하지 않은 데이터셋으로 학습한 Mask R-CNN**의 성능을 비교한다. 최종적으로 GAN 생성 이미지를 사용한 Mask R-CNN에서 성능 개선을 관찰했다.

**이 검증 방식이 중요하다.** 생성된 이미지가 "그럴듯해 보인다"는 것으로는 부족하고, **실제 과제 성능이 오르는가**가 진짜 기준이다.

## 3. 사전지식 (A to Z)

### 3.1 GAN의 기본 원리

생성기 G와 판별기 D가 서로 반대되는 목표로 경쟁한다. G는 진짜 같은 데이터를 만들려 하고, D는 진짜와 가짜를 구별하려 한다.

**논문 식 (1) — 미니맥스 목적함수**

```
min_G max_D V(D, G) = E_{x~p_data(x)}[log D(x)] + E_{z~p_z(z)}[log(1 − D(G(z)))]
```

- G는 이 목적함수를 **최소화**하려 하고, D는 **최대화**하려 한다
- `x`: 실제 데이터
- `z`: 잠재 변수(입력)
- `G(z)`: 생성된 가짜 데이터

→ 상세: [05_생성모델_GAN·Diffusion.md](../01_foundations/05_생성모델_GAN·Diffusion.md)의 `### GAN의 원리`

### 3.2 조건부 GAN과 pix2pix

**조건부 GAN(CGAN)**: 무작위 잡음에서 아무 이미지나 만드는 대신, 조건을 함께 넣어 무엇을 만들지 지정한다.

**pix2pix**: 조건이 **이미지**인 경우다. 스케치를 사진으로, 흑백을 컬러로 바꾸는 식의 이미지 변환이다. **쌍을 이룬(paired) 데이터**가 필요하다.

논문은 결론부에서 **"Pix2Pix를 사용해 합성 증강 이미지를 만들었다"** 고 명시한다. 논문 Fig. 2의 제목도 "The Conditional Generative Adversarial Network (CGAN) model architecture"다.

**이 논문에서의 매핑**

```
G: z → y
   상태가 나쁜 치아 이미지  →  상태가 좋은 치아 이미지
```

→ 상세: [05_생성모델_GAN·Diffusion.md](../01_foundations/05_생성모델_GAN·Diffusion.md)의 `### pix2pix`, `### 조건부 GAN`

### 3.3 짝지어진 데이터를 만드는 문제 — 이 논문의 핵심 트릭

**pix2pix는 입력과 출력이 정확히 대응하는 쌍이 필요하다.** 그런데 같은 치아의 "나쁜 상태"와 "좋은 상태" 사진을 동시에 갖는 것은 불가능하다.

**이 논문의 해법**: **좋은 상태 이미지에 노이즈 함수를 적용해 인위적으로 나쁜 상태를 만든다.**

```
원본 317장 (실제 치아)
      ↓ 노이즈 함수 적용
저품질 317장 (인위적으로 훼손)
      ↓
이 둘이 짝을 이룬 병렬 데이터셋 (parallel dataset)
      ↓
GAN 학습: 나쁜 상태 → 좋은 상태 변환을 배운다
```

**논문의 서술**: 모든 치아 이미지에 노이즈 함수를 적용해 저품질 버전을 생성했고, **일부 이미지에서는 치아가 제거됐다.** 이 과정 끝에 원본 데이터셋의 병렬 버전인 317장의 저품질 치아 이미지를 얻었다.

**"치아가 제거됐다"는 부분이 중요하다.** 단순한 노이즈가 아니라 **치아를 지우는 변형**까지 포함했다는 뜻이고, 그러면 GAN이 없는 치아를 그려 넣는 법을 배우게 된다.

### 3.4 인스턴스 분할과 Mask R-CNN

인스턴스 분할은 같은 클래스의 개체를 **개별적으로** 구분해 픽셀 단위로 분할한다. 치아는 여러 개가 붙어 있으므로 "치아 영역"만으로는 부족하고 **몇 번 치아인지** 구분해야 한다.

**Mask R-CNN 구조**: Faster R-CNN(영역 제안 → 상자·클래스)에 **마스크 예측 브랜치**를 추가하고, **RoIAlign**으로 양자화 오차를 제거한 모델이다.

→ 상세: [03_비전_검출·분할·키포인트.md](../01_foundations/03_비전_검출·분할·키포인트.md)의 `### 인스턴스 분할과 파놉틱 분할`

### 3.5 U-Net과 ResNet34

이 논문의 생성기는 **U-Net 기반**이고, 다운샘플링에 **ResNet34**를 썼다.

**U-Net을 생성기로 쓰는 이유**: 스킵 연결로 입력 이미지의 구조 정보를 출력에 직접 전달한다. 이미지 변환에서 입력의 형태를 유지해야 하므로 필수적이다. pix2pix 원논문도 U-Net 생성기를 쓴다.

→ 상세: [03_비전_검출·분할·키포인트.md](../01_foundations/03_비전_검출·분할·키포인트.md)의 `### U-Net과 인코더-디코더`

## 4. 방법론 단계별 해부

### 4.1 전체 데이터 생성 파이프라인 (논문 Fig. 3)

논문이 네 단계로 그림을 나눈다.

```
(A) 노이즈 함수로 조작된 이미지 생성
    실제 치아 317장 → 노이즈 적용 → 저품질 317장
                                    (일부는 치아가 제거됨)
        ↓
(B) 생성된 병렬 치아 이미지로 GAN 학습
    (조작됨 → 조작 안 됨) 매핑을 학습
        ↓
(C) 실제 치아 이미지를 좋은 상태 / 나쁜 상태로 분류
    (12개 치아가 모두 건강해 보이는지 기준)
        ↓
(D) 나쁜 상태의 치아에 GAN을 적용해 데이터 생성
    → 좋은 상태 치아 이미지 120장 생성
```

### 4.2 GAN 학습 전략 — 단계적 사전학습

**문제**: 논문의 지적대로 GAN은 학습이 어렵다.

> GAN 학습이 어려운 이유 중 하나는 **생성기 모델과 판별기 모델을 동시에 학습시키면 한 모델의 개선이 다른 모델의 희생으로 이어질 수 있기** 때문이다.

**해법**: 각각 **개별적으로 사전학습한 뒤 결합**한다.

```
1단계: 생성기 사전학습
   병렬 데이터셋으로 U-Net 기반 생성기를 학습
   (다운샘플링에 ResNet34 사용)
        ↓
2단계: 생성기를 원본 전체에 적용
   317장의 가짜 치아 이미지 생성
        ↓
3단계: 판별기 사전학습
   위에서 생성한 이미지들로 D를 사전학습
   (Convolution + BatchNorm + ReLU + Residual 모듈로 구성된 분류 모델)
        ↓
4단계: 두 사전학습 모델을 GAN으로 결합
   병렬 데이터셋으로 함께 학습
        ↓
5단계: 학습된 GAN을 나쁜 상태 이미지에 적용
   → 좋은 상태 이미지 120장 생성
```

**이 단계적 학습 전략이 이 논문의 실무적 기여다.** GAN의 균형 문제를 회피하는 실용적 방법이다.

**"더 높은 해상도의 인공 치아 이미지를 생성하기 위해 이 생성기를 사용했다"** 는 서술도 있어, 해상도 개선 목적도 함께 있었던 것으로 보인다.

**상태 분류 기준이 단순하다.** "12개 치아가 모두 건강해 보이는가"라는 이분법이다. 치주 전문의가 제1저자이므로 임상적 판단이 개입했을 것으로 보이나, **판정 절차와 판정자 수가 원문에 명시되지 않았다.**

### 4.6 Mask R-CNN 성능 비교 설계

```
데이터셋 A: 생성 데이터 없음 (원본만)
데이터셋 B: 생성 데이터 포함 (원본 + GAN + 노이즈)
        ↓
같은 Mask R-CNN을 각각 학습
        ↓
AP와 AR로 성능 비교
```

**이것이 다운스트림 평가(downstream evaluation)** 다. 생성 이미지의 품질을 FID 같은 지표로 재는 대신, **실제 과제에서 도움이 되는가**로 판정한다.

**생성 데이터 활용 연구에서 가장 설득력 있는 검증 방식**이다.

## 5. 핵심 수식

**식 (1) — GAN 미니맥스 목적함수**

```
min_G max_D V(D, G) = E_{x~p_data(x)}[log D(x)] + E_{z~p_z(z)}[log(1 − D(G(z)))]
```

**읽는 법**

- D는 최대화: 진짜 `x`에 대해 `D(x)`를 1로(앞항 최대), 가짜 `G(z)`에 대해 `D(G(z))`를 0으로(뒷항 최대)
- G는 최소화: `D(G(z))`를 1로 만들어 뒷항을 최소화

**생성기의 매핑**

```
G: z → y
```

논문의 서술: G는 적대적 판별기 D에 의해 부정 표본으로 기각되지 않는 이미지를 생성하도록 학습된다. D는 실제 데이터와 G가 생성한 데이터를 구별하는 분류기다.

**평가지표 (논문 식 3, 4)**

```
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
```

## 8. 한계와 반박 대응

### 8.1 실제 데이터에서의 개선이 미미하다 — 가장 중요한 지점

**이 논문에서 가장 먼저 준비해야 할 반박이다.**

```
실제 치아 데이터 분할 AP: 0.156 → 0.172  (+0.016)
AR 지표 4개는 모두 미세하게 하락
```

**반복 실험과 표준편차가 없어 이 차이가 통계적으로 유의한지 알 수 없다.**

**답변 전략** — 세 단계로 답한다.

1. **인정한다**: "실제 치아 데이터에서의 개선 폭은 작습니다. 주 지표인 분할 AP가 0.156에서 0.172로 0.016 올랐고, 재현율 지표는 오히려 미세하게 낮아졌습니다."
2. **패턴을 해석한다**: "정밀도는 오르고 재현율은 내려간 패턴인데, 생성 데이터가 모델을 더 보수적으로 만든 것으로 읽힙니다. 확신이 없는 검출을 덜 내놓게 된 것입니다."
3. **필요한 검증을 말한다**: "이 차이가 우연이 아니라고 주장하려면 여러 시드로 반복 실험해 표준편차를 제시했어야 합니다. 논문에 그 부분이 없는 것이 가장 큰 약점입니다."

### 8.2 시뮬레이션 결과를 일반화 근거로 쓴 논리가 약하다

논문은 시뮬레이션 데이터에서의 큰 개선을 근거로 **"이 방법의 일반화 성능을 증명할 수 있다"** 고 주장한다.

**이 논리에 문제가 있다.**

시뮬레이션 데이터는 **PIL로 그린 직사각형 치아 12개**다. 실제 치아보다 **훨씬 단순하고 규칙적**이다.

```
논문의 논리:  단순한 데이터에서 잘 됨  →  일반적으로 잘 됨
실제 함의:    단순한 데이터에서 잘 됨  →  복잡한 데이터에서는 확인 필요
```

**오히려 두 결과의 대비가 말해 주는 것**은, 이 방법이 **데이터 복잡도에 민감하다**는 것이다. 단순한 데이터에서는 2배 개선, 복잡한 실제 데이터에서는 10% 개선이다.

**답변 전략**: "시뮬레이션 결과가 일반화를 증명한다는 논문의 서술은 과합니다. 단순한 합성 데이터에서 잘 되는 것이 복잡한 실제 데이터에서 잘 될 근거가 되지 않습니다. 오히려 두 결과의 격차가 이 방법이 데이터 복잡도에 민감하다는 것을 보여 준다고 봅니다. 시뮬레이션은 파이프라인이 원리적으로 작동한다는 온전성 검사로 보는 것이 정확한 위치입니다."

**이렇게 답하면 논문의 주장을 그대로 반복하는 것보다 훨씬 신뢰를 준다.**

### 8.3 데이터 분할이 명시되지 않았다 — 데이터 누수 우려

**학습/검증/테스트 분할이 원문에 없다.**

이것이 심각한 이유:

- GAN이 **원본 317장 전체**로 학습됐다
- 생성된 120장은 그 원본의 정보를 담고 있다
- 만약 테스트 세트가 그 317장 중에서 나왔다면, **테스트 이미지의 정보가 학습 데이터에 새어 들어간 것**이다

**생성 데이터 연구에서 가장 흔하고 치명적인 오류**다.

**올바른 설계**

```
1. 먼저 데이터를 학습/테스트로 나눈다
2. GAN은 학습 세트로만 학습한다
3. 생성 데이터도 학습 세트에만 추가한다
4. 테스트는 손대지 않은 실제 데이터로만 한다
```

**답변 전략**: "논문에 데이터 분할이 명시돼 있지 않습니다. GAN이 원본 전체로 학습됐다면 테스트 세트의 정보가 생성 데이터를 통해 학습에 들어갔을 가능성이 있습니다. 이 경우 성능이 낙관적으로 평가됩니다. 생성 데이터 연구에서는 GAN 학습 전에 데이터를 먼저 나누고, 테스트는 손대지 않은 실제 데이터로만 하는 것이 원칙입니다."

→ 관련: [05_생성모델_GAN·Diffusion.md](../01_foundations/05_생성모델_GAN·Diffusion.md)의 `### 합성 데이터로 학습하기`

### 8.4 노이즈 함수가 정의되지 않았다

**"노이즈 함수를 적용해 저품질 이미지를 만들었다"** 는 서술만 있고 그 함수가 무엇인지 없다.

이것이 문제인 이유:

1. **재현이 불가능하다**
2. **GAN이 배우는 것이 무엇인지 알 수 없다.** 가우시안 노이즈를 제거하는 것과 지워진 치아를 그려 넣는 것은 전혀 다른 과제다
3. 논문은 "일부 이미지에서는 치아가 제거됐다"고 했는데, **제거 비율과 방식**이 결정적인데 명시되지 않았다

**답변 전략**: "노이즈 함수의 정의가 논문에 없어 재현이 어렵습니다. 특히 일부 이미지에서 치아를 제거했다고 했는데, 그 비율과 방식에 따라 GAN이 배우는 과제가 완전히 달라집니다. 명시했어야 하는 부분입니다."

### 8.5 GAN 생성이 120장뿐이다

원본 317장에서 **120장**만 생성했다. 나쁜 상태로 분류된 이미지가 120장이었기 때문으로 보이지만, **논문에 명시되지 않았다.**

전체 754장 중 GAN 생성은 **16%** 에 불과하고, 나머지 증강(317장)은 노이즈 함수로 만든 것이다.

**따라서 "GAN 덕분에 성능이 올랐다"는 인과를 주장하기 어렵다.** 노이즈 증강의 기여와 GAN의 기여가 분리되지 않았다.

**필요했던 제거 실험**

| 조건 | 데이터 |
|------|--------|
| A | 원본만 (317) |
| B | 원본 + 노이즈 증강 (634) |
| C | 원본 + GAN 생성 (437) |
| D | 원본 + 노이즈 + GAN (754) |

**B와 C를 비교해야 GAN의 고유 기여를 알 수 있는데, 그 실험이 없다.**

**답변 전략**: 이 지적을 스스로 하면 강하다. "전체 754장 중 GAN 생성은 120장이고 나머지 317장은 노이즈 함수로 만든 것입니다. 두 증강의 기여가 분리되지 않아서, 개선이 GAN 때문인지 노이즈 증강 때문인지 알 수 없습니다. 노이즈 증강만 쓴 조건과 GAN만 쓴 조건을 나눠 비교했어야 합니다."

### 8.6 생성 이미지의 품질 평가가 없다

FID, LPIPS 같은 생성 품질 지표가 전혀 없다. 논문 Fig. 4에 예시 이미지만 제시된다.

**대응 논리**: 다운스트림 평가가 더 본질적인 검증이라는 점은 맞다. 하지만 생성 품질 지표가 함께 있으면 **"성능이 안 오른 이유가 생성 품질 때문인지"** 를 진단할 수 있다. 실제 데이터에서 개선이 작았으므로 이 진단이 필요했다.

다만 [T02 문서 8.2절](T02_전후면의류_확산모델.md)에서 다룬 대로, FID는 ImageNet 기반 특징을 쓰므로 의료 영상에서는 신뢰도가 떨어진다. 그 한계를 함께 말하면 균형 잡힌 답이 된다.

### 8.7 절대 성능이 낮다

실제 데이터에서 분할 AP가 0.172다. 전치부 12개 치아를 개별 식별하는 과제인데, 이 성능으로는 임상에 쓸 수 없다.

**논문이 이 절대 수준을 논하지 않았다.** 상대적 개선만 이야기한다.

**대응 논리**: 이 논문의 목적이 "임상 적용 가능한 분할 모델 개발"이 아니라 **"생성 데이터가 도움이 되는가"** 를 검증하는 것이었다고 위치를 정확히 말한다. Mask R-CNN 자체의 최적화는 범위 밖이다.

### 8.8 Table 3의 비단조성

400 → 450에서 6개 지표가 하락한다. 논문은 "대부분의 지표가 개선된다"고만 하고 이 예외를 설명하지 않는다.

**대응 논리**: 데이터 포인트가 3개뿐이고 반복 실험이 없어 경향을 주장하기 어렵다. 400과 450의 차이가 우연일 가능성이 있다. **더 촘촘한 구간과 반복 실험이 필요했다.**

### 8.9 IRB 면제 승인의 범위

IRB **면제(exemption)** 승인이다. 면제는 통상 익명화된 기존 데이터의 후향적 분석에 적용된다.

생성 데이터를 만들어 배포하거나 다른 목적으로 쓰는 것이 면제 범위에 포함되는지는 별도 검토가 필요하다. **의료 AI 면접이라면 이 지점을 물어볼 수 있다.**

## 10. 예상 질문

#### Q001. 이 논문을 설명해 주세요. 🟢

**의도:** 기본 확인 질문. 유일한 의료 영상 논문이라 관심이 높다.

**답변:** 의료 영상 데이터 부족 문제를 GAN으로 푸는 연구입니다. 치과 분야는 개인정보 문제로 데이터 수집이 어렵고 전문의가 픽셀 단위로 라벨링해야 해서 비용이 큽니다. 저희는 pix2pix 계열의 조건부 GAN으로 치아 영상을 생성했는데, 짝지어진 데이터를 만드는 방법이 특징입니다. 같은 치아의 나쁜 상태와 좋은 상태 사진을 동시에 가질 수는 없으니, 원본 317장에 노이즈 함수를 적용해 인위적으로 훼손한 버전을 만들어 병렬 데이터셋을 구성했습니다. 그것으로 GAN을 학습시켜 나쁜 상태에서 좋은 상태로 가는 변환을 배우게 했고, 실제 나쁜 상태 이미지에 적용해 120장을 생성했습니다. 최종적으로 754장을 확보했고, Mask R-CNN을 생성 데이터를 넣은 경우와 안 넣은 경우로 학습시켜 비교했습니다.

**꼬리질문:** 성능이 얼마나 개선됐습니까?

#### Q002. 성능이 얼마나 개선됐습니까? 🔴

**의도:** 결과를 정확히 말하는지, 부풀리는지 본다. **이 논문에서 가장 중요한 질문이다.**

**답변:** 두 종류의 데이터에서 결과가 크게 달랐습니다. 시뮬레이션 데이터에서는 개선이 극적이었는데 분할 AP가 0.388에서 0.750으로 거의 두 배가 됐고 모든 지표가 올랐습니다. 그런데 실제 치아 영상에서는 개선 폭이 훨씬 작았습니다. 분할 AP가 0.156에서 0.172로 0.016 올랐고, 재현율 지표는 오히려 네 개 모두 미세하게 낮아졌습니다. 정밀도는 오르고 재현율은 내려간 패턴이라, 생성 데이터가 모델을 더 보수적으로 만든 것으로 읽힙니다. 그리고 반복 실험과 표준편차가 논문에 없어서, 실제 데이터의 이 작은 차이가 통계적으로 유의한지는 확인할 수 없습니다.

**꼬리질문:** 그럼 이 방법이 효과가 있다고 말할 수 있습니까?

#### Q003. 시뮬레이션에서는 두 배 개선인데 실제 데이터에서는 10퍼센트입니다. 왜 그렇습니까? 🔴

**의도:** 결과의 격차를 해석할 수 있는지 본다. 이 논문의 핵심 논점이다.

**답변:** 네 가지 가능성을 생각합니다. 첫째, 시뮬레이션 데이터가 훨씬 단순합니다. PIL로 그린 직사각형 치아 12개라 구조가 규칙적이라서 GAN이 그 규칙을 쉽게 학습하고 유용한 변형을 만들 수 있습니다. 둘째, 실제 치아 영상의 변동이 GAN 용량을 넘었을 수 있습니다. 형태와 색, 조명, 개인차가 큰데 317장으로 학습한 GAN이 그 분포를 충분히 포착하지 못한 것입니다. 셋째, 생성한 120장이 원본과 너무 비슷해서 새 정보를 거의 주지 못했을 수 있습니다. 넷째, 기준선 자체가 다릅니다. 시뮬레이션은 0.388에서 시작해 올릴 여지가 컸는데 실제 데이터는 0.156에서 시작합니다. 문제 자체가 훨씬 어렵습니다.

**꼬리질문:** 그럼 시뮬레이션 결과에 어떤 의미를 두십니까?

#### Q004. 논문은 시뮬레이션 결과가 일반화를 증명한다고 하는데 동의하십니까? 🔴

**의도:** 자기 논문의 주장을 비판적으로 볼 수 있는지 본다.

**답변:** 그 서술은 과하다고 봅니다. 단순한 합성 데이터에서 잘 되는 것이 복잡한 실제 데이터에서도 잘 될 근거가 되지 않습니다. 논리의 방향이 반대여야 하는데, 실제 데이터에서 잘 되면 그 방법이 견고하다고 말할 수 있지 그 역은 성립하지 않습니다. 오히려 두 결과의 격차가 말해 주는 것은 이 방법이 데이터 복잡도에 민감하다는 것입니다. 시뮬레이션 실험의 정확한 위치는 일반화 증명이 아니라 온전성 검사라고 생각합니다. 파이프라인이 원리적으로 작동한다는 것, 즉 생성 데이터를 넣으면 성능이 오를 수 있는 구조라는 것을 확인하는 용도입니다. 그 이상을 주장하려면 다른 실제 의료 영상 도메인에서 검증했어야 합니다.

**의도:** 개선 능력을 종합적으로 본다.

**답변:** 네 가지입니다. 첫째, 데이터 분할을 먼저 명시하고 GAN 학습 전에 테스트 세트를 떼어 놓겠습니다. 생성 데이터 연구에서 가장 흔한 오류가 여기서 나옵니다. 둘째, 증강 종류별 제거 실험을 넣겠습니다. 원본만, 노이즈 증강만, GAN 생성만, 둘 다 이렇게 네 조건을 비교해야 GAN의 고유 기여를 알 수 있습니다. 셋째, 반복 실험으로 표준편차를 제시하겠습니다. 실제 데이터의 개선 폭이 0.016 정도로 작았는데, 이게 우연이 아니라고 주장하려면 여러 시드에서의 편차를 보여야 합니다. 넷째, 노이즈 함수를 명시하고 가능하면 임상 소견에 근거해 설계하겠습니다. 제1저자가 치주과 교수님이시니 실제 치아 상태 악화의 양상을 반영할 수 있었을 것입니다.

**꼬리질문:** 그 네 가지 중에 하나만 할 수 있다면 무엇을 하시겠습니까?
