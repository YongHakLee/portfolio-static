## 프로젝트 4건 30초 스크립트

**그대로 읽으면 30초가 되는 분량이다. 소리 내어 연습할 것.**

### P1 — 모바일 LiDAR 3차원 계측 (2023.01–2026.06)

> 스마트폰 LiDAR로 물체의 실제 치수를 재는 프레임워크입니다. 사진만으로는 크기를 알 수 없어서 기존에는 참조물을 같이 찍고 촬영 환경을 통제해야 했습니다. 저희는 딥러닝으로 찾은 키포인트에 LiDAR 깊이를 매핑해 참조물 없이 치수를 냈습니다. 핵심 문제는 2D 키포인트가 3D 실제 경계와 어긋나는 것이었고, 깊이 맵의 경계선으로 보정했습니다. 보정 전 19.2퍼센트였던 오차가 5퍼센트 대로 떨어졌습니다. 여기에 길이에서 무게나 둘레를 추정하는 회귀식을 더해 의류와 농산물, 인체에 같은 구조를 적용했습니다. 3년 반 동안 진행했고 논문 3편과 특허 2건으로 정리했습니다.

### P2 — 가스배관 센서 탐지 (2022.01–2023.01)

> 배관 내부를 주행하는 로봇의 센서 데이터만으로 접합부와 만곡부를 찾는 과제였습니다. 처음 적용한 다층 신경망이 성능이 안 나왔는데, 원인이 입력 크기가 고정되어야 한다는 구조적 제약이었습니다. 배관 구간은 길이가 제각각인데 자르거나 채우는 과정에서 신호가 왜곡되고 있었습니다. 그래서 입력 길이 제약이 없는 트리 모델로 바꾸고, 분산과 최대-최소 차이, 행 간 변화량 같은 파생변수로 가변 길이 구간을 고정 길이 벡터로 요약했습니다. 접합부를 먼저 찾고 그 사이를 만곡부 후보로 다시 정의하는 단계적 접근으로 문제를 나눴습니다.

### P3 — 상품 추천 멀티모달 (2021.01–2022.01)

> 온라인 쇼핑에서 상품 간 관계를 예측하는 연구입니다. 이미지만으로는 브랜드나 소재를 알 수 없고 텍스트만으로는 디자인을 알 수 없어서 두 정보를 결합했습니다. 모바일 연산 제약을 고려해 MobileNetV3로 이미지를, Sentence-BERT로 텍스트를 벡터화했습니다. 설계의 핵심은 두 상품 벡터를 그냥 이어 붙이는 대신 차이의 절댓값을 함께 넣은 것입니다. 관계 판정에 필요한 유사도 정보를 모델이 스스로 계산하게 두지 않고 직접 제공한 것입니다. 이미지만 70퍼센트, 텍스트만 96퍼센트인데 결합하면 98퍼센트가 나왔습니다. 제1저자로 게재했고 석사 학위논문의 토대가 됐습니다.

### P4 — 영상 기반 미세먼지 추정 (2020.01–2021.01)

> 카메라 영상으로 미세먼지 농도를 추정하는 연구입니다. 국가 측정망은 정확하지만 비용이 크고 도시에 몰려 있어 사각지대가 생깁니다. 기존 방식은 사진 한 장씩만 분석했는데, 미세먼지는 공기 중을 떠다니는 입자라 시간에 따른 흐름 자체가 정보입니다. 저희는 연속 프레임의 픽셀별 평균을 시간적 사전정보로 만들어 원본과 함께 입력했습니다. 라즈베리 파이로 구현해 저비용 장비에서 돌아가도록 연산량을 조정했고, 실내외와 챔버에서 검증했습니다. 실외에서 개선 폭이 훨씬 컸는데, 바람이 불어 입자가 실제로 유동하는 상황에서 시간 정보가 기여하기 때문입니다.

## 자주 헷갈리는 개념 구분

| | A | B | 결정적 차이 |
|---|---|---|---|
| **시맨틱 vs 인스턴스 분할** | 픽셀에 클래스만 | 개체별로 구분 | 개 두 마리를 하나로 보는가 따로 보는가 |
| **GAN vs 확산모델** | 적대적 경쟁, 한 번에 생성 | 노이즈 예측 회귀, 여러 단계 | **확산은 정답이 있는 지도학습** → 안정적 |
| **정밀도 vs 재현율** | 양성이라 한 것 중 맞은 비율 | 진짜 양성 중 잡아낸 비율 | 오경보를 줄일까 놓침을 줄일까 |
| **MAE vs RMSE** | 절대오차 평균 | 제곱오차 제곱근 | RMSE는 **큰 오차 하나에 크게 흔들린다** |
| **L1 vs L2 정규화** | 계수를 0으로 만듦 | 전체적으로 작게 | 제약 영역이 마름모냐 원이냐 |
| **PCA vs PLS** | 입력의 분산 최대 방향 | **입력·출력 공분산** 최대 방향 | PCA는 목표변수를 안 본다 |
| **랜덤포레스트 vs 부스팅** | **분산**을 줄임, 병렬 | **편향**을 줄임, 순차 | 튜닝 민감도와 성능 상한 |
| **U-Net 스킵 vs ResNet 잔차** | 채널로 **이어 붙임**(concat) | 같은 위치에 **더함**(add) | 위치 정보 복원 vs 기울기 전달 |
| **z-depth vs radial depth** | 광축 방향 성분 | 카메라에서 점까지 직선거리 | **역투영식은 z-depth 전제** |
| **정밀도(precision) vs 정확도(accuracy)** | 반복 일관성·표현 자릿수 | 참값과의 근접도 | 논문의 "0.00001cm"는 전자 |
| **헤드앤숄더 천정형 vs 바닥형** | 봉우리 3개, 하락 신호 | **골 3개, 상승 신호** | **T11은 바닥형(역헤드앤숄더)** |
| **출원 vs 등록** | 신청서 제출 | 심사 통과, 권리 발생 | 특허 2건 중 등록은 1건 |
| **IPFS 저장 vs 영속성** | 분산 저장 프로토콜 | **보장되지 않음** | 핀(pin)하지 않으면 사라진다 |

> → [03_papers/T12](03_papers/T12_SBT_분산스토리지.md) Q003

**8. 시뮬레이션에서는 2배인데 실제 데이터는 왜 10%입니까? (T08)** 🔴

> → [03_papers/T08](03_papers/T08_치과영상_GAN생성.md) Q004

**9. 검증이 모델 4명인데 신뢰할 수 있습니까? (T03)** 🔴
> **상대적 개선 주장(19.2%→5%)과 절대 정확도 주장을 구분** → 전자는 표본이 작아도 방향이 유지, 후자는 근거 약함
