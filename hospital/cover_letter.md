# 재는 일을 해 왔습니다

이용학

저는 통계학을 기반으로 데이터 분석과 인공지능 모델 개발을 해 온 사람입니다. 건국대학교 응용통계학과에서 학사와 석사를 마치고 박사 과정을 밟았으며, 학위 과정과 병행하여 2023년부터 2026년까지 주식회사 머스트리 기술팀에서 근무했습니다. 학교에서는 방법론을 다듬고 회사에서는 그 방법론이 실제 환경에서 견디는지를 확인하는, 두 가지 일을 함께 해 왔습니다.

제 연구는 서로 다른 종류의 데이터를 하나로 묶어 의미 있는 값을 얻는 데 초점이 있었습니다. 석사 과정에서는 상품의 시각 이미지와 텍스트로 된 메타데이터를 결합해 상품 사이의 관계를 예측하는 방법론을 다뤘습니다. 한쪽만 보아서는 놓치는 정보를 다른 쪽이 채워 준다는 것, 그리고 그 결합이 모바일 환경에서도 감당할 만한 연산량 안에서 가능하다는 것을 확인한 작업이었습니다. 박사 과정에서는 이 관심이 3차원으로 옮겨 갔습니다. 모바일 기기의 LiDAR 센서가 주는 거리 정보와 딥러닝으로 찾은 키포인트를 결합해, 별도의 참조물이나 통제된 촬영 환경 없이 물체의 실제 치수를 재는 프레임워크를 만들었습니다. 2차원 이미지에서 찾은 키포인트가 3차원 공간의 실제 경계와 어긋나는 문제는 깊이 맵의 경계선을 이용해 보정했고, 이렇게 얻은 길이 값을 바탕으로 무게나 둘레처럼 직접 재기 어려운 값을 추정하는 데까지 범위를 넓혔습니다.

실무에서는 결과가 잘 나오지 않을 때 모델을 키우기보다 데이터를 다시 보는 편이었습니다. 로봇 센서 데이터로 가스배관의 접합부와 만곡부를 찾아내는 과제에서는 처음 사용한 신경망이 기대만큼 동작하지 않았습니다. 입력 크기가 고정되어야 한다는 제약이 원인이라고 판단해 트리 기반 모델로 방향을 바꾸고, 원본 신호를 그대로 넣는 대신 분산이나 최대-최소 차이, 행 사이의 변화량 같은 파생 변수를 만들어 학습에 사용했습니다. 접합부를 먼저 찾은 뒤 그 사이 구간을 만곡부 후보로 다시 정의하는 식으로 문제를 나눈 것도 이때였습니다. 영상으로 미세먼지 농도를 추정하는 과제에서도 고가의 측정 장비 대신 라즈베리 파이와 연속된 영상 프레임의 변화량을 활용해, 현장에서 바로 쓸 수 있는 형태로 만드는 데 집중했습니다. 좋은 장비나 무거운 모델 없이도 필요한 수준에 도달할 수 있는 지점을 찾는 일에 익숙합니다.

이 과정에서 국내외 학술지에 여러 편의 논문을 게재했고, 한 편은 제1저자로, 한 편은 교신저자로 참여했습니다. 국가 연구개발 과제는 제안 단계부터 수행까지 여러 건에 참여했으며, 특허는 두 건을 출원해 그중 한 건이 등록되었습니다. 다룬 분야는 대기환경, 온라인 유통, 산업 설비, 농업, 헬스케어까지 서로 꽤 달랐습니다. 도메인이 바뀔 때마다 배워야 할 것은 많았지만, 무엇을 재야 하고 무엇이 오차를 만드는지 확인하는 일의 구조는 크게 다르지 않았습니다. 낯선 데이터를 처음부터 이해해야 하는 상황이 저에게는 익숙한 편입니다.

일을 할 때는 문제부터 분명히 하려고 합니다. 성능이 나오지 않으면 원인을 짐작해 여러 가지를 한꺼번에 바꾸기보다, 어디서 어긋나는지 먼저 확인하고 하나씩 검증하며 고쳐 나갔습니다. 결과가 정리되면 논문이나 특허, 문서로 남겨 다음 사람이 같은 지점에서 다시 헤매지 않도록 하는 일도 제 몫이라고 생각해 왔습니다.

특별히 앞서가는 기술을 다뤄 왔다고 말씀드리기는 어렵습니다. 다만 주어진 데이터에서 무엇이 문제인지 확인하고, 검증할 수 있는 방식으로 하나씩 고쳐 나가는 일을 오래 반복해 왔습니다. 새로운 분야의 데이터를 이해하는 데는 시간이 걸리겠지만, 그 시간을 성실하게 쓰겠습니다.
