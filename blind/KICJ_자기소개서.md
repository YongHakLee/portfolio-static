## 1. 지원동기 및 직무 전문성 향상 노력 *(500~700자)*

한국형사법무정책연구원은 객관적 데이터와 실증 분석을 토대로 형사·법무 정책의 방향을 제시하는 국가 정책연구기관입니다. 저는 응용통계학을 전공하며 6년간 서로 다른 분야의 데이터를 수집·전처리하고 분석해 온 경험이, 범죄 통계와 설문조사 등 방대한 정량 자료를 다루는 연구 지원 업무에 직접 기여할 수 있다고 판단하여 지원하였습니다.

박사과정과 기업 연구원으로 일하며 미세먼지·의료·농업·산업 센서 등 성격이 전혀 다른 도메인의 데이터를 다뤘고, 낯선 자료 구조에도 빠르게 적응해 Python과 Pandas로 정제·분석하는 역량을 길렀습니다. 특히 SQLD·ADsP 자격 취득과 9편의 공동 연구를 통해 통계적 추론과 재현 가능한 분석 절차의 중요성을 체득하였습니다.

직무 전문성을 높이기 위해 저는 분석 도구 숙련을 넘어, 분석 결과가 정책의 근거로 쓰이는 맥락을 이해하려 노력해 왔습니다. 국가 R&D 과제를 제안·수행하며 연구가 사회 문제 해결로 이어지는 과정을 경험하였고, 이 경험을 형사정책이라는 공익적 영역에서 이어가고자 합니다. 입사 후에는 연구진의 데이터 전처리와 통계 분석을 신속·정확하게 지원하고, 형사사법 데이터의 특수성을 익혀 신뢰받는 분석 실무자로 성장하겠습니다.

## 2. 조직이해능력: 입사 후 직무 목표와 구체적 달성 계획 *(500~700자)*

한국형사법무정책연구원은 범죄와 형사·법무 정책을 실증적으로 연구하여 국가 정책의 근거를 제공하는 기관입니다. 저는 이곳의 데이터 분석 지원 직무를, 연구진이 정책적 통찰에 집중할 수 있도록 데이터의 수집·정제·분석 기반을 든든히 받치는 역할로 이해하고 있습니다. 이에 저의 직무 목표는 '연구진이 믿고 맡길 수 있는 데이터 분석 실무자'가 되는 것이며, 이를 세 단계 계획으로 이루고자 합니다.

**첫째, 적응기(1~2개월)** 에는 형사사법 데이터의 구조와 용어, 연구원의 분석 절차와 보안 규정을 빠르게 익히겠습니다. 범죄 통계·설문조사 자료의 특성을 파악하고 기존 분석 사례를 학습하여 조직의 방식에 맞추겠습니다.

**둘째, 실무 정착기** 에는 제 강점인 Python·Pandas 역량을 활용해 결측치 처리·이상치 검토 등 반복되는 전처리 과정을 스크립트로 자동화하고, 분석 코드를 재사용 가능하도록 문서화하여 연구진의 시간을 절약하겠습니다.

**셋째, 기여 확장기** 에는 단순 분석·시각화 지원을 넘어, 데이터에서 발견한 패턴과 시사점을 연구진에게 먼저 제안하는 능동적 분석가로 성장하겠습니다. 다양한 도메인의 데이터를 다뤄 온 경험을 바탕으로 정확하고 재현 가능한 분석을 제공하여, 연구 성과의 신뢰도를 높이는 데 기여하겠습니다.

## 3. 의사소통능력: 성공적 협업 사례 *(500~700자)*

로봇 센서 데이터로 가스배관의 접합부·만곡부 구간을 자동 탐지하는 프로젝트에서 저는 데이터 전처리와 모델링을 맡았습니다. 초기에 팀은 딥러닝(MLP) 모델을 고수했으나 정확도가 0.18~0.34에 그쳐 진척이 없었고, '더 깊은 신경망을 쌓자'는 팀원과 '접근 방식 자체를 바꾸자'는 저 사이에 견해 차이가 있었습니다.

저는 감정적 설득 대신 근거로 대화하는 방식을 택했습니다. 먼저 실패 원인을 입력 크기 고정 제약과 데이터 불균형으로 정리해 공유하였고, 트리 기반 모델과 파생변수(분산, 최대-최소 차이, 행 간 차이 등)를 적용한 소규모 실험 결과를 수치로 제시하였습니다. 상대가 우려한 재현성과 해석 가능성도 함께 검증해 보여주며 합의를 이끌었습니다.

그 결과 팀은 Random Forest·LightGBM으로 방향을 전환하였고, 접합부 예측 정확도 0.87, 만곡부 0.98이라는 성과를 달성하여 솔루션을 실제 패키징 단계까지 완성하였습니다. 이 경험을 통해 협업에서의 이견은 '누가 옳은가'가 아니라 '무엇이 문제를 해결하는가'를 데이터로 함께 확인할 때 비로소 성과로 이어진다는 것을 배웠습니다. 형사정책 연구에서도 연구진과 근거를 공유하며 조율하는 소통으로 팀의 결과에 기여하겠습니다.

## 4. 자원관리능력: 제한된 자원의 효율적 과제 수행 *(500~700자)*

**[과제 목표]** 기업 연구원으로 근무하던 시기, AI 모델 학습에 필요한 대규모 상품 데이터를 짧은 기간 안에 확보하는 것이 과제였습니다. 인력과 시간이 부족해 수작업 수집만으로는 마감을 맞출 수 없는 상황이었습니다.

**[자원 관리 방식]** 저는 부족한 인력을 자동화로 대체하기로 하고 Python 기반 크롤링 파이프라인을 구축하였습니다. 사이트 구조 변화에 대비해 예외 처리를 넣고, 중복·결측 데이터를 자동으로 걸러 Pandas로 정제하는 단계를 함께 설계하여 수집과 전처리를 하나의 흐름으로 통합하였습니다. 한정된 저장·연산 자원을 고려해 학습에 꼭 필요한 필드만 선별 수집하도록 하였습니다.

**[목표 달성]** 그 결과 수작업 대비 수집 시간을 크게 단축하고, 모델 학습에 바로 투입할 수 있는 정제된 데이터셋을 기한 내에 확보하였습니다. 반복 작업을 자동화한 덕분에 남은 시간을 데이터 품질 검증과 모델 개선에 집중할 수 있었습니다.

이 경험은 제한된 자원 상황에서 '무엇을 자동화하고 무엇에 사람의 시간을 쓸 것인가'를 구분하는 판단력을 길러 주었습니다. 형사정책 연구의 데이터 수집·정제 업무에서도 반복 과정을 자동화하여, 한정된 연구 자원을 분석과 해석이라는 본질에 집중시키겠습니다.

## 5. 직업윤리: 공익적 태도와 직업윤리의 중요성 *(400~600자)*

저는 데이터를 다루는 사람의 첫 번째 윤리는 '결과를 있는 그대로 보고하는 정직함'이라고 생각합니다. 연구 과정에서 기대에 못 미치는 성능이 나올 때 수치를 유리하게 포장하고 싶은 유혹이 있지만, 저는 미세먼지 측정 연구에서 실외 정확도가 실내보다 낮게 나온 결과와 그 한계를 그대로 기록하고 원인을 분석해 후속 개선의 근거로 삼았습니다. 데이터를 왜곡하지 않는 태도가 결국 더 신뢰받는 연구로 이어진다고 믿기 때문입니다.

또한 저는 기술이 공익에 기여해야 한다는 가치를 중요하게 여깁니다. 적대적 샘플 공격에 대한 인공지능의 취약점을 분석하는 국가 R&D 과제에 참여하며, AI가 악용될 수 있는 지점을 미리 밝혀 사회적 위험에 대비하는 연구의 가치를 경험하였습니다.

형사법무정책 연구는 개인의 자유와 안전, 민감한 개인정보를 다루는 영역인 만큼 분석의 객관성과 데이터 보안·비밀 유지가 무엇보다 중요합니다. 저는 어떤 압력 속에서도 데이터의 무결성과 연구윤리를 지키고, 분석 결과가 공정한 정책의 근거가 되도록 책임 있게 임하겠습니다.

## 6. 경험 및 경력기술서 *(2000자 이내)*

**[전공 및 데이터 분석 역량]**
학사·석사를 거쳐 현재 응용통계학과 박사과정(2026년 8월 졸업 예정)에 재학 중입니다. 통계학 기반 위에 머신러닝·딥러닝을 접목하여, 데이터의 수집부터 전처리·모델링·결과 해석까지 전 과정을 독립적으로 수행할 수 있습니다. 분석 언어로는 Python을 주로 사용하며 Pandas·NumPy를 이용한 데이터프레임 처리와 PyTorch 기반 모델 개발에 능숙합니다.

**[형사법 분야에 대한 이해]**
데이터 분석 역량과 더불어, 저는 과거 검찰직 공무원 시험을 준비하며 형법과 형사소송법을 체계적으로 공부한 경험이 있습니다. 전문 법조인 수준은 아니지만, 범죄의 구성요건과 형사절차의 기본 구조, 형사사법에서 사용되는 주요 용어와 개념에 대한 기초적인 이해를 갖추고 있습니다. 이는 형사정책 연구가 다루는 문제의 맥락을 파악하고 연구진과 원활히 소통하는 데 도움이 될 것이며, 데이터 분석 역량과 결합되어 '형사 도메인을 이해하는 분석 지원자'라는 저만의 강점이 될 것이라 생각합니다.

**[데이터 분석 자격 및 수상]**
데이터 실무 역량을 객관적으로 검증하기 위해 ADsP(데이터분석 준전문가)와 SQLD(SQL 개발자) 자격을 취득하였으며, 참여한 AI 솔루션이 정보통신산업진흥원 'AI 바우처 우수사례'로 선정되었습니다.

**[연구·논문]**
국내외 학술지에 총 9편의 논문을 공동 저자(제1저자·교신저자 포함)로 게재하였습니다. 상품 추천을 위한 시각 이미지·메타데이터 통합 분석, 미세먼지 농도 추정, 강화학습, 3D 인체 계측 등 서로 다른 주제를 다루며, 낯선 도메인의 데이터라도 문제 정의부터 분석까지 수행하는 적응력을 길렀습니다.

**[프로젝트 및 실무 경험]**
세 곳의 기업 기술개발팀에서 연구원으로 근무하며 실무 데이터를 다루었습니다.
① 소형 컴퓨터·Python·OpenCV 기반 저비용 미세먼지 측정 시스템 개발 (시계열 딥러닝+PLS-DA 통계 결합, 실내 86% 정확도)
② 크롤링 기반 데이터 수집·정제 자동화 파이프라인 구축
③ 로봇 센서 데이터에서 파생변수를 설계해 Random Forest·LightGBM으로 가스배관 구간 탐지 (정확도 0.87~0.98)
④ 모바일 LiDAR와 딥러닝을 결합한 3D 치수 측정 알고리즘 연구 및 API 구현

**[국가 R&D 및 특허]**
'적대적 샘플 공격에 대한 인공지능 취약점 분석·대응' 등 다수의 국가 R&D 과제를 제안·수행하였고, '2D·3D 데이터 융합 기반 신체 둘레 측정' 방법으로 특허를 출원·등록(발명자)하였습니다.

이러한 경험을 통해 저는 다양한 형태의 데이터를 빠르게 이해하고, 통계적 근거에 기반해 재현 가능한 분석을 수행하며, 반복 업무를 자동화하는 역량을 갖추었습니다. 여기에 검찰직 준비 과정에서 쌓은 형사법 분야에 대한 기초적 이해를 더해, 형사정책 연구의 데이터 분석 지원 업무에 성실히 기여하겠습니다.
